# 吴澄学术图谱考据

## 一、人物生平概览

**生卒年份**：公元1249年-1333年（南宋末年至元代）

**籍贯考辨**：
- 抚州崇仁（今江西省崇仁县）人
- 字幼清，号草庐
- 谥号"文正"
- 故城遗址在今崇仁县境内
- 吴澄墓在今崇仁县

**时代背景**：
吴澄处于宋末元初，其时宋元交替，学术发展。吴澄是这一时期著名的理学家，与许衡并称"北许南吴"。

**师承关系**：
- 无明确师承记载
- 通晓理学
- 与朱熹后学交往
- 弟子：众多

**生平经历**：
- 自幼聪慧，博学多才
- 宋末时隐居不仕
- 元代时被征召，任国子监丞
- 后辞官归隐
- 潜心著述
- 卒于家中

## 二、学术突破与理论创新

### （一）《易纂言》——易学研究的集大成

**核心理论创新**：
吴澄作《易纂言》，是元代易学研究的重要著作。

**主要内容**：
- 以朱熹《周易本义》为基础
- 阐发易学理论
- 发展易学象数

**技术方法革新**：
- **文本注释**：详细注释《周易》
- **理论阐发**：阐发易学理论
- **象数发展**：发展易学象数

**与前人的差异化**：
吴澄之前的易学研究多注重义理或象数，吴澄综合各家，使易学研究更加全面。

### （二）《礼记纂言》——礼学研究的贡献

**礼学贡献**：
吴澄作《礼记纂言》，是元代礼学研究的重要著作。

**主要内容**：
- 整理《礼记》

**技术方法革新**：
- **文本整理**：整理《礼记》文本
- **理论阐发**：阐发礼学理论
- **系统整合**：整合礼学理论

### （三）理学研究

**理学贡献**：
吴澄是元代重要的理学家。

**主要内容**：

**技术方法革新**：

# 基于吴澄经学研究的经典文献分析系统
class ClassicAnalyzer:
    def __init__(self):
        self.classics = {
            '周易': 'yijing',
            '尚书': 'shujing',
            '诗经': 'shijing_poetry',
            '礼记': 'liji',
            '春秋': 'chunqiu'
        }
    
    def analyze_text(self, classic_name, chapter):
        """分析经典文本"""
        text = self.load_text(classic_name, chapter)
        analysis = {
            'text': text,
            'keywords': self.extract_keywords(text),
            'themes': self.identify_themes(text),
            'interpretations': self.get_interpretations(classic_name, chapter)
        }
        return analysis
    
    def compare_interpretations(self, classic_name, chapter):
        """比较不同注释"""
        interpretations = self.load_interpretations(classic_name, chapter)
        comparison = {}
        for scholar, interp in interpretations.items():
            comparison[scholar] = {
                'interpretation': interp,
                'features': self.extract_features(interp)
            }
        return comparison
