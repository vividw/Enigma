# 冲煞计算的集合论表示

## 1. 冲煞的集合论基础

择日学中的"冲煞"概念可严格表述为集合论中的运算。通过定义适当的集合和运算规则，可以对冲煞关系进行形式化分析。

### 1.1 基本集合定义

**天干集合**：$G = \{甲, 乙, 丙, 丁, 戊, 己, 庚, 辛, 壬, 癸\}$

**地支集合**：$Z = \{子, 丑, 寅, 卯, 辰, 巳, 午, 未, 申, 酉, 戌, 亥\}$

**六十甲子集合**：$J = G \times Z$ 在循环等价下的等价类

$$|J| = 60$$

### 1.2 五行集合划分

天干按五行划分：

$$G_{木} = \{甲, 乙\}, \quad G_{火} = \{丙, 丁\}, \quad G_{土} = \{戊, 己\}$$

$$G_{金} = \{庚, 辛\}, \quad G_{水} = \{壬, 癸\}$$

地支按五行划分：

$$Z_{木} = \{寅, 卯\}, \quad Z_{火} = \{巳, 午\}, \quad Z_{土} = \{辰, 戌, 丑, 未\}$$

$$Z_{金} = \{申, 酉\}, \quad Z_{水} = \{亥, 子\}$$

### 1.3 生肖集合

生肖与地支一一对应：

$$S = \{鼠, 牛, 虎, 兔, 龙, 蛇, 马, 羊, 猴, 鸡, 狗, 猪\}$$

存在双射 $\phi: Z \to S$。

## 2. 六冲关系的集合表示

### 2.1 六冲作为二元关系

六冲关系 $R_{冲} \subseteq Z \times Z$：

$$R_{冲} = \{(子, 午), (午, 子), (丑, 未), (未, 丑), (寅, 申), (申, 寅),$$

$$(卯, 酉), (酉, 卯), (辰, 戌), (戌, 辰), (巳, 亥), (亥, 巳)\}$$

### 2.2 六冲关系的性质

**对称性**：$(a, b) \in R_{冲} \Rightarrow (b, a) \in R_{冲}$

**反自反性**：$\forall a \in Z, (a, a) \notin R_{冲}$

**非传递性**：$(a, b) \in R_{冲}, (b, c) \in R_{冲} \nRightarrow (a, c) \in R_{冲}$

### 2.3 冲煞判定函数

定义冲煞判定函数：

$$\chi_{冲}(a, b) = \begin{cases} 1 & \text{if } (a, b) \in R_{冲} \\ 0 & \text{otherwise} \end{cases}$$

## 3. 三合三会的集合结构

### 3.1 三合局

三合关系将地支分为四组：

$$T_1 = \{申, 子, 辰\} \text{ (水局)}$$

$$T_2 = \{亥, 卯, 未\} \text{ (木局)}$$

$$T_3 = \{寅, 午, 戌\} \text{ (火局)}$$

$$T_4 = \{巳, 酉, 丑\} \text{ (金局)}$$

### 3.2 三合的集合性质

**划分性**：$\{T_1, T_2, T_3, T_4\}$ 构成 $Z$ 的划分

$$\bigcup_{i=1}^4 T_i = Z, \quad T_i \cap T_j = \emptyset \text{ for } i \neq j$$

**等势性**：$|T_i| = 3, \forall i$

### 3.3 三会局

三会关系按方位划分：

$$H_{东} = \{寅, 卯, 辰\}, \quad H_{南} = \{巳, 午, 未\}$$

$$H_{西} = \{申, 酉, 戌\}, \quad H_{北} = \{亥, 子, 丑\}$$

## 4. 刑害关系的集合运算

### 4.1 相刑关系

相刑关系 $R_{刑} \subseteq Z \times Z$ 包含：

**无恩之刑**：$(寅, 巳), (巳, 申), (申, 寅)$

**恃势之刑**：$(丑, 戌), (戌, 未), (未, 丑)$

**无礼之刑**：$(子, 卯), (卯, 子)$

**自刑**：$(辰, 辰), (午, 午), (酉, 酉), (亥, 亥)$

### 4.2 六害关系

六害关系 $R_{害} \subseteq Z \times Z$：

$$R_{害} = \{(子, 未), (丑, 午), (寅, 巳), (卯, 辰), (申, 亥), (酉, 戌)\}$$

### 4.3 关系复合

冲煞的综合效应可通过关系复合描述：

$$R_{综合} = R_{冲} \cup R_{刑} \cup R_{害}$$

## 5. 冲煞的布尔代数

### 5.1 冲煞集合的运算

**并集**：$A \cup B$ 表示A煞或B煞

**交集**：$A \cap B$ 表示A煞且B煞

**补集**：$A^c$ 表示非A煞

**差集**：$A \setminus B$ 表示A煞但非B煞

### 5.2 冲煞的布尔函数

复杂冲煞条件表示为布尔函数：

$$f(x_1, x_2, \ldots, x_n) = x_1 \wedge (x_2 \vee x_3) \wedge \neg x_4$$

其中 $x_i = \chi_{煞_i}$。

### 5.3 主析取范式

任何冲煞条件可化为标准形式：

$$f = \bigvee_{i} \bigwedge_{j} x_{ij}^{\epsilon_{ij}}$$

## 6. 冲煞的格论结构

### 6.1 冲煞偏序集

定义冲煞强度偏序：

$$a \preceq b \text{ iff } 煞_a \subseteq 煞_b$$

### 6.2 格运算

**交（meet）**：$a \wedge b = 煞_a \cap 煞_b$

**并（join）**：$a \vee b = 煞_a \cup 煞_b$

### 6.3 完备格

冲煞集合构成完备格：

$$\sup S = \bigcup_{s \in S} s, \quad \inf S = \bigcap_{s \in S} s$$

## 7. 冲煞的算法实现

### 7.1 冲煞判定算法

输入：日柱地支 $z_d$，命主生肖 $z_m$

输出：冲煞类型集合

```
算法冲煞判定:
1. 初始化空集合 S
2. if (z_d, z_m) in R_冲: S.add("冲")
3. if (z_d, z_m) in R_刑: S.add("刑")
4. if (z_d, z_m) in R_害: S.add("害")
5. return S
```

### 7.2 冲煞规避算法

输入：目标期 $T$，命主信息 $M$，冲煞集合 $S$

输出：可用日期集合

$$T_{可用} = \{t \in T : \forall s \in S, \chi_s(t, M) = 0\}$$

### 7.3 复杂度分析

冲煞判定时间复杂度：$O(1)$（哈希表查找）

冲煞规避时间复杂度：$O(|T| \cdot |S|)$

## 8. 结论

集合论为冲煞分析提供了严格的形式化框架。集合、关系、布尔代数、格论等概念与择日学中的冲煞判定、三合三会、刑害关系等建立了精确的对应关系。该模型可用于冲煞计算的算法实现和自动化择日系统。
