# 大衍之数的概率模型

## 1. 模型概述

大衍之数是《周易》揲蓍成卦的核心算法，通过49根蓍草的分揲操作确定卦象。本模型建立大衍之数的概率模型，分析其随机过程、概率分布，以及与卦象生成的统计关系。

## 2. 大衍之数的基本操作

### 2.1 大衍之数五十

《周易·系辞》："大衍之数五十，其用四十有九。"

**数学表达**：

$$N_{大衍} = 50$$
$$N_{实用} = 49$$

### 2.2 分而为二

将49根蓍草随机分为两部分：

$$49 = L + R$$

其中 $L$ 为左手之数，$R$ 为右手之数。

**概率分布**：

假设随机分揲，则：

$$L \sim Uniform\{1, 2, ..., 48\}$$
$$R = 49 - L$$

### 2.3 挂一象三

从右手取1根挂于指间：

$$R' = R - 1$$

### 2.4 揲之以四

左右手分别以4根为一组计数：

$$L = 4 \cdot q_L + r_L, \quad r_L \in \{0, 1, 2, 3\}$$
$$R' = 4 \cdot q_R + r_R, \quad r_R \in \{0, 1, 2, 3\}$$

**余数分布**：

若 $L$ 均匀分布，则余数 $r_L$ 的分布：

$$P(r_L = k) = \frac{12}{48} = \frac{1}{4}, \quad k \in \{1, 2, 3\}$$
$$P(r_L = 0) = \frac{11}{48} \approx \frac{1}{4}$$

（因为49 = 4×12 + 1，余0的情况略少）

### 2.5 归奇于扐

将左右余数加上挂一的1根：

$$N_{归奇} = r_L + r_R + 1$$

**归奇数的可能值**：

- $r_L = 1, r_R = 1$: $N_{归奇} = 3$
- $r_L = 1, r_R = 2$: $N_{归奇} = 4$
- $r_L = 1, r_R = 3$: $N_{归奇} = 5$
- $r_L = 2, r_R = 1$: $N_{归奇} = 4$
- ...

归奇数的可能值：$\{3, 4, 5, 6, 7, 8, 9\}$

## 3. 三变成爻的概率

### 3.1 一变

一变后剩余蓍草：

$$N_1 = 49 - N_{归奇,1}$$

**一变归奇数的分布**：

$$P(N_{归奇,1} = 5) = P(r_L + r_R = 4) = \frac{3}{16}$$
$$P(N_{归奇,1} = 9) = P(r_L + r_R = 8) = \frac{3}{16}$$

（假设左右独立且余数1-3等概率）

### 3.2 二变

二变从 $N_1$ 根开始，同样操作：

$$N_2 = N_1 - N_{归奇,2}$$

### 3.3 三变

三变从 $N_2$ 根开始：

$$N_3 = N_2 - N_{归奇,3}$$

### 3.4 成爻

三变后，以4除之得爻数：

$$爻数 = \frac{N_3}{4}$$

**爻数的可能值**：

$$爻数 \in \{6, 7, 8, 9\}$$

- 6：老阴（变爻）
- 7：少阳（不变）
- 8：少阴（不变）
- 9：老阳（变爻）

### 3.5 爻数的概率分布

**理论概率**（传统说法）：

$$P(6) = P(9) = \frac{1}{16}$$
$$P(7) = P(8) = \frac{7}{16}$$

**推导**：

三变归奇数之和决定爻数：

$$N_{归奇,总} = N_{归奇,1} + N_{归奇,2} + N_{归奇,3}$$

$$爻数 = \frac{49 - N_{归奇,总}}{4}$$

归奇数通常为5或9：
- 5：概率 3/4
- 9：概率 1/4

三变组合：
- (5,5,5): 爻数 = (49-15)/4 = 8.5 → 实际为8或9
- (5,5,9): 爻数 = (49-19)/4 = 7.5 → 实际为7或8
- ...

精确计算需考虑余数的精确分布。

## 4. 六爻成卦的概率

### 4.1 成卦过程

重复大衍之数操作6次，得6爻：

$$卦 = (爻_1, 爻_2, 爻_3, 爻_4, 爻_5, 爻_6)$$

其中 $爻_i \in \{6, 7, 8, 9\}$。

### 4.2 本卦与变卦

**本卦**：由6、7、8、9的阴阳属性确定
- 6、8为阴（--）
- 7、9为阳（—）

**变卦**：变爻（6、9）翻转

### 4.3 卦的概率分布

**无变爻卦**：

$$P(无变爻) = P(全为7或8) = (\frac{7}{8})^6 \approx 0.448$$

**一变卦**：

$$P(一变) = C_6^1 \cdot \frac{2}{16} \cdot (\frac{7}{8})^5 \approx 0.384$$

**多变卦**：

$$P(k变) = C_6^k \cdot (\frac{2}{16})^k \cdot (\frac{7}{8})^{6-k}$$

### 4.4 特定卦的概率

特定本卦的概率：

$$P(特定卦) = (\frac{7}{16})^n \cdot (\frac{7}{16})^{6-n} = (\frac{7}{16})^6$$

其中 $n$ 为阳爻数。

$$P(特定卦) = (\frac{7}{16})^6 \approx 0.0037$$

## 5. 大衍之数的随机过程

### 5.1 马尔可夫链模型

大衍之数操作可视为马尔可夫链：

**状态**：当前蓍草数 $N \in \{1, 2, ..., 49\}$

**转移概率**：

$$P(N_{t+1} = N_t - k \mid N_t) = P(N_{归奇} = k)$$

### 5.2 吸收态

吸收态为 $N \leq 4$：

$$爻数 = \left\lfloor \frac{N}{4} \right\rfloor$$

### 5.3 期望步数

从49根到成爻的期望操作次数：

$$E[步数] = 3$$

（三变成一爻）

### 5.4 极限分布

六爻成卦的极限分布：

$$\pi(卦) = \prod_{i=1}^6 P(爻_i)$$

## 6. 大衍之数的统计检验

### 6.1 均匀性检验

检验各爻数是否等概率：

**原假设** $H_0$：$P(6) = P(7) = P(8) = P(9) = \frac{1}{4}$

**检验统计量**（卡方检验）：

$$\chi^2 = \sum_{i} \frac{(O_i - E_i)^2}{E_i}$$

### 6.2 独立性检验

## 8. 大衍之数的信息论分析

### 8.1 信息量

每爻的信息量：

$$H(爻) = -\sum_{x \in \{6,7,8,9\}} P(x) \log_2 P(x)$$

**理论值**：

$$H(爻) = -2 \cdot \frac{1}{16} \log_2 \frac{1}{16} - 2 \cdot \frac{7}{16} \log_2 \frac{7}{16} \approx 1.37 \text{ bits}$$

### 8.2 卦的信息量

六爻卦的信息量：

$$H(卦) = 6 \cdot H(爻) \approx 8.22 \text{ bits}$$

### 8.3 变卦的信息量

考虑变卦的额外信息：

$$H(变卦) = H(本卦) + H(变爻位置)$$
