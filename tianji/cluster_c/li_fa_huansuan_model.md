# 中国古代历法换算统一框架

## 一、历法体系的概念框架

### 1.1 历法类型的数学分类

中国古代历法可分为三类：阳历、阴历、阴阳合历。

**定义（历法类型）**：历法类型空间 $\mathcal{C}$ 定义为：

$$\mathcal{C} = \{	ext{阳历}, 	ext{阴历}, 	ext{阴阳合历}\}$$

**定义（阳历）**：阳历以回归年为基本周期，忽略朔望月。

**定义（阴历）**：阴历以朔望月为基本周期，忽略回归年。

**定义（阴阳合历）**：阴阳合历同时考虑回归年和朔望月，通过置闰协调两者。

### 1.2 历法参数的数学表示

**定义（历法参数）**：历法参数向量 $\mathbf{p}$ 定义为：

$$\mathbf{p} = (T_{	ext{回归}}, T_{	ext{朔望}}, T_{	ext{交点}}, T_{	ext{近点}}, \ldots)^T$$

### 1.3 历法周期的数学结构

**定义（历法周期群）**：历法周期构成加法群 $(\mathbb{R}, +)$ 的子群。

**定理（周期关系）**：历法周期满足：

$$n \cdot T_{	ext{朔望}} pprox m \cdot T_{	ext{回归}}$$

其中 $n, m$ 为整数。

## 二、主要历法体系

### 2.1 古六历

**定义（古六历）**：古六历包括黄帝历、颛顼历、夏历、殷历、周历、鲁历。

**定理（古六历区别）**：古六历主要区别在于岁首和历元不同。

### 2.2 三统历

**定义（三统历）**：三统历由刘歆编制，采用 $19$ 年 $7$ 闰法则。

**定理（三统历周期）**：三统历的章蔀纪元周期为：

$$T_{	ext{三统}} = 1539 	ext{ 年}$$

### 2.3 授时历

**定义（授时历）**：授时历由郭守敬编制，精度最高。

**定理（授时历精度）**：授时历回归年长度为：

$$T_{	ext{回归}} = 365.2425 	ext{ 日}$$

与现代值 $365.2422$ 日仅差 $0.0003$ 日。

### 2.4 时宪历

**定义（时宪历）**：时宪历采用定气定朔，为现代农历的基础。

## 四、历法换算的算法实现

### 4.1 公历转农历

**算法（公历转农历）**：

输入：公历年 $Y$，月 $M$，日 $D$

1. 计算儒略日数 $JD$
2. 计算该年春节的儒略日数 $JD_{	ext{春节}}$
3. 计算农历年：$Y_{	ext{农历}} = Y$（若 $JD \ge JD_{	ext{春节}}$）或 $Y - 1$（否则）
4. 计算该年各朔日
5. 确定农历月：找到包含 $JD$ 的朔望月
6. 计算农历日：$D_{	ext{农历}} = JD - JD_{	ext{朔}} + 1$

输出：农历年月日

### 4.2 农历转公历

**算法（农历转公历）**：

输入：农历年 $Y$，月 $M$，日 $D$，是否闰月 $L$

1. 计算该年春节的儒略日数 $JD_{	ext{春节}}$
2. 计算该年各朔日
3. 找到第 $M$ 个朔日（考虑闰月）
4. 计算公历日期：$JD = JD_{	ext{朔}} + D - 1$
5. 将 $JD$ 转换为公历日期

输出：公历年月日

### 4.3 干支历换算

**算法（干支历换算）**：

输入：公历年 $Y$，月 $M$，日 $D$

1. 计算儒略日数 $JD$
2. 计算年干支：$(Y - 4) \mod 60$
3. 计算月干支：根据年干和月确定
4. 计算日干支：$(JD + 49) \mod 60$
5. 计算时干支：根据日干和时辰确定

输出：年月日时的干支

LUNAR_DATA_TABLE = {

def lunar_to_solar(lunar_year, lunar_month, lunar_day, is_leap=False):
    """农历转公历"""
    # 计算该年春节的公历日期
    spring_festival = get_spring_festival(lunar_year)

    # 计算该年各月天数
    month_days = LUNAR_DATA_TABLE[lunar_year]["days"]
    leap_month = LUNAR_DATA_TABLE[lunar_year]["leap"]

    # 计算目标日期
    days = sum(month_days[:lunar_month-1]) + lunar_day - 1
    if is_leap and lunar_month >= leap_month:
        days += month_days[leap_month-1]

    return spring_festival + timedelta(days=days)
```

def calculate_ganzhi(year, month, day):
    """计算干支"""
    # 年干支
    year_gan = (year - 4) % 10
    year_zhi = (year - 4) % 12

    # 月干支（根据年干确定月干起始）
    month_gan_start = (year_gan * 2 + 1) % 10
    month_gan = (month_gan_start + month - 1) % 10
    month_zhi = (month + 1) % 12

    # 日干支
    jd = gregorian_to_jd(year, month, day)
    day_ganzhi = (jd + 49) % 60

    return year_gan, year_zhi, month_gan, month_zhi, day_ganzhi
```
