# 七政四余星历计算模型

## 一、七政四余的概念体系

### 1.1 七政的数学定义

七政指日、月、金、木、水、火、土七颗天体。

**定义（七政集合）**：七政集合 $\mathcal{Q}$ 定义为：

$$\mathcal{Q} = \{	ext{日}, 	ext{月}, 	ext{金}, 	ext{木}, 	ext{水}, 	ext{火}, 	ext{土}\}$$

### 1.2 四余的数学定义

四余是四个虚拟天体的统称。

**定义（四余集合）**：四余集合 $\mathcal{Y}$ 定义为：

$$\mathcal{Y} = \{	ext{罗睺}, 	ext{计都}, 	ext{紫气}, 	ext{月孛}\}$$

### 1.3 七政四余的轨道参数

**定义（轨道参数）**：每个天体的位置由轨道参数决定：

- 平黄经 $L$
- 平近点角 $M$
- 偏心率 $e$
- 轨道倾角 $i$
- 升交点黄经 $\Omega$
- 近地点幅角 $\omega$

## 二、七政星历计算模型

### 2.1 太阳位置计算

**定义（太阳平黄经）**：太阳平黄经 $L_\odot$ 为：

$$L_\odot = 280.46646° + 36000.76983° \cdot T$$

**定义（太阳平近点角）**：太阳平近点角 $M_\odot$ 为：

$$M_\odot = 357.52911° + 35999.05029° \cdot T$$

**定理（太阳黄经）**：太阳黄经 $\lambda_\odot$ 为：

$$\lambda_\odot = L_\odot + 1.914666471° \sin(M_\odot) + 0.019994643° \sin(2M_\odot)$$

### 2.2 月亮位置计算

**定义（月亮平黄经）**：月亮平黄经 $L_\moon$ 为：

$$L_\moon = 218.3164477° + 481267.88123421° \cdot T$$

**定义（月亮平近点角）**：月亮平近点角 $M_\moon$ 为：

$$M_\moon = 134.9633964° + 477198.8675055° \cdot T$$

**定理（月亮黄经）**：月亮黄经 $\lambda_\moon$ 需考虑数十项摄动：

$$\lambda_\moon = L_\moon + \sum_{i} A_i \sin(\phi_i)$$

### 2.3 行星位置计算

**定义（行星平黄经）**：行星平黄经 $L_p$ 为：

$$L_p = L_0 + n \cdot T$$

其中 $n$ 为平均运动速度。

**定理（行星黄经）**：行星黄经需考虑轨道偏心率和其他行星的摄动。

## 三、四余星历计算模型

### 3.1 罗睺与计都的定义

**定义（罗睺）**：罗睺是月亮升交点的虚拟天体。

**定义（计都）**：计都是月亮降交点的虚拟天体。

**定理（罗睺计都黄经）**：罗睺黄经 $\lambda_{	ext{罗}}$ 为：

$$\lambda_{	ext{罗}} = \Omega_\moon$$

计都黄经 $\lambda_{	ext{计}}$ 为：

$$\lambda_{	ext{计}} = \Omega_\moon + 180°$$

### 3.2 紫气的定义

**定义（紫气）**：紫气是木星的余气，计算方法有多种。

**定理（紫气黄经）**：紫气黄经 $\lambda_{	ext{紫}}$ 的一种计算为：

$$\lambda_{	ext{紫}} = \lambda_	ext{木} + 30°$$

### 3.3 月孛的定义

**定义（月孛）**：月孛是月亮远地点的虚拟天体。

**定理（月孛黄经）**：月孛黄经 $\lambda_{	ext{孛}}$ 为：

$$\lambda_{	ext{孛}} = \lambda_\moon + 180° + \omega_\moon$$

## 四、星历计算的VSOP87模型

### 4.1 VSOP87概述

**定义（VSOP87）**：VSOP87是法国天体力学研究所开发的行星位置计算理论。

**定理（VSOP87精度）**：VSOP87计算行星位置的精度可达0.01角秒。

### 4.2 VSOP87的级数展开

**定义（VSOP87级数）**：行星黄经表示为泊松级数：

$$\lambda = \sum_{i} A_i \cdot T^{p_i} \cdot \cos(B_i + C_i \cdot T)$$

### 4.3 VSOP87的实现

```python
def vsop87_longitude(planet, T):
    """使用VSOP87计算行星黄经"""
    L = 0
    for term in VSOP87_TERMS[planet]["L"]:
        A, B, C, p = term
        L += A * (T ** p) * math.cos(B + C * T)
    return L % (2 * math.pi)
```

## 五、星历计算的ELP-2000模型

### 5.1 ELP-2000概述

**定义（ELP-2000）**：ELP-2000是月亮位置计算的高精度理论。

**定理（ELP-2000精度）**：ELP-2000计算月亮位置的精度可达0.001角秒。

### 5.2 ELP-2000的级数展开

**定义（ELP-2000级数）**：月亮黄经表示为：

$$\lambda_\moon = \sum_{i} A_i \sin(\phi_i)$$

其中 $\phi_i$ 为各种周期的相位组合。

## 六、星历计算的高级算法

### 6.1 查表法

```python
# 七政四余星历表（简化）
XINGLI_TABLE = {
    "日": {"period": 365.25, "L0": 280.46646},
    "月": {"period": 27.32166, "L0": 218.3164477},
    "金": {"period": 224.70, "L0": 181.9798},
    "木": {"period": 4332.59, "L0": 100.46435},
    "水": {"period": 87.97, "L0": 252.25084},
    "火": {"period": 686.98, "L0": 355.45332},
    "土": {"period": 10759.22, "L0": 49.94432}
}

def calculate_planet_longitude(planet, days_from_epoch):
    """计算行星黄经"""
    data = XINGLI_TABLE[planet]
    L = (data["L0"] + 360 * days_from_epoch / data["period"]) % 360
    return L
```

### 6.2 插值法

```python
from scipy import interpolate

def interpolate_longitude(times, longitudes, target_time):
    """插值计算黄经"""
    f = interpolate.interp1d(times, longitudes, kind='cubic')
    return f(target_time)
```
