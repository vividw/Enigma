# 三奇六仪遁甲规则的形式化表达

## 一、问题定义

三奇六仪遁甲是奇门遁甲的核心机制，涉及六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅）在六仪（戊、己、庚、辛、壬、癸）中的隐遁规则。本节建立遁甲规则的严格数学形式化体系。

## 二、六甲与六仪的对应关系

### 2.1 六甲集合

设六甲集合 $J = \{甲子, 甲戌, 甲申, 甲午, 甲辰, 甲寅\}$。

### 2.2 六仪集合

设六仪集合 $Y = \{戊, 己, 庚, 辛, 壬, 癸\}$。

### 2.3 遁甲映射

定义遁甲映射 $\psi: J \to Y$：

$$\psi(甲子) = 戊$$

$$\psi(甲戌) = 己$$

$$\psi(甲申) = 庚$$

$$\psi(甲午) = 辛$$

$$\psi(甲辰) = 壬$$

$$\psi(甲寅) = 癸$$

### 2.4 映射的数学性质

**定理**：$\psi$ 是双射（一一对应）。

**证明**：

- 单射：不同的甲对应不同的仪
- 满射：每个仪都有对应的甲

故 $\psi$ 为双射，$|J| = |Y| = 6$。

## 三、遁甲的群论解释

### 3.1 六甲的循环结构

六甲按顺序排列形成循环：

$$甲子 \to 甲戌 \to 甲申 \to 甲午 \to 甲辰 \to 甲寅 \to 甲子$$

这对应于6阶循环群 $C_6 \cong \mathbb{Z}_6$。

### 3.2 六仪的循环结构

六仪按天干顺序排列：

$$戊 \to 己 \to 庚 \to 辛 \to 壬 \to 癸 \to 戊$$

同样对应于 $C_6 \cong \mathbb{Z}_6$。

### 3.3 遁甲映射的同构性质

**定理**：遁甲映射 $\psi$ 诱导群同构 $\tilde{\psi}: C_6 \to C_6$。

**证明**：

设六甲的群运算为顺序递推，六仪的群运算同样为顺序递推。

对任意 $j_1, j_2 \in J$：

$$\psi(j_1 \cdot j_2) = \psi(j_1) \cdot \psi(j_2)$$

验证：

- 甲子 $\cdot$ 甲戌 = 甲申
- $\psi(甲子) \cdot \psi(甲戌)$ = 戊 $\cdot$ 己 = 庚 = $\psi(甲申)$

故 $\psi$ 保持群运算，为群同态。又因 $\psi$ 为双射，故为群同构。

## 四、遁甲的地盘排布

### 4.1 地盘的基本结构

地盘是奇门遁甲的基础排盘，固定不变（除中五宫寄宫规则外）。

### 4.2 六仪在地盘的分布

六仪在地盘的分布遵循"遁甲"原则——甲隐于仪下。

**阳遁**：六仪从局数对应的宫位开始顺布。

**阴遁**：六仪从局数对应的宫位开始逆布。

### 4.3 三奇的分布

三奇（乙、丙、丁）按固定规则分布：

- 乙：日奇
- 丙：月奇
- 丁：星奇

三奇的排布与六仪互补，填充六仪未占据的宫位。

### 4.4 数学公式

设局数为 $n$，遁类型为 $t$（0=阳遁，1=阴遁）。

**六仪位置**：

$$P_Y(i, n, t) = \begin{cases} ((n - 1 + i) \bmod 9) + 1 & \text{if } t = 0 \\ ((10 - n - i + 9) \bmod 9) + 1 & \text{if } t = 1 \end{cases}$$

其中 $i = 0, 1, 2, 3, 4, 5$ 对应戊、己、庚、辛、壬、癸。

**三奇位置**：

三奇从第四宫（巽宫）开始，按遁类型顺逆分布：

$$P_Q(j, t) = \begin{cases} ((4 - j + 9) \bmod 9) + 1 & \text{if } t = 0 \text{（阳遁逆布）} \\ ((4 + j - 1) \bmod 9) + 1 & \text{if } t = 1 \text{（阴遁顺布）} \end{cases}$$

其中 $j = 0, 1, 2$ 对应乙、丙、丁。

## 五、旬首与遁甲

### 5.1 旬的定义

一旬为10个时辰，由六甲轮流值旬。

**旬首**：每旬的第一个时辰，由甲值旬。

### 5.2 旬首的计算

设时柱干支序号为 $k$（0-59），则旬首序号为：

$$k_{\text{xun}} = \lfloor k / 10 \rfloor \times 10$$

对应的六甲为：

$$j_{\text{xun}} = J[\lfloor k / 10 \rfloor]$$

### 5.3 旬首与六仪的对应

旬首六甲决定当值的六仪：

$$y_{\text{xun}} = \psi(j_{\text{xun}})$$

### 5.4 旬首宫位的确定

旬首六仪在地盘的位置即为旬首宫位：

$$g_{\text{xun}} = P_Y^{-1}(y_{\text{xun}}, n, t)$$

## 六、遁甲的形式化系统

### 6.1 形式化语言

定义遁甲系统的基本符号：

- 常量：六甲、六仪、三奇、九宫
- 变量：局数、遁类型、时辰
- 函数：排布函数、映射函数

### 6.2 公理系统

**公理1（遁甲唯一性）**：每甲唯一对应一仪。

$$\forall j \in J, \exists! y \in Y: \psi(j) = y$$

**公理2（排布完备性）**：地盘九宫被六仪三奇完全覆盖。

$$\bigcup_{i=0}^{5} P_Y(i) \cup \bigcup_{j=0}^{2} P_Q(j) = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}$$

**公理3（排布互斥性）**：六仪三奇不重叠。

$$P_Y(i) \cap P_Q(j) = \emptyset, \forall i, j$$

### 6.3 推理规则

**规则1（遁甲传递）**：若甲 $j$ 遁于仪 $y$，则 $y$ 所在宫位的性质由 $j$ 决定。

**规则2（旬首主导）**：值旬之甲决定当值六仪，进而影响排盘。

### 7.2 地盘排布算法

```
算法：ArrangeDiPanWithDunJia
输入：局数 n，遁类型 t
输出：地盘排布 diPan[10]

1. 初始化 diPan[1..9] = null
2. 
   // 排布六仪
3. 对于 i 从 0 到 5：
      如果 t == 阳遁：
         pos = ((n - 1 + i) mod 9) + 1
      否则：
         pos = ((10 - n - i + 9) mod 9) + 1
      diPan[pos] = 六仪[i]
4. 
   // 排布三奇
5. 如果 t == 阳遁：
      对于 j 从 0 到 2：
         pos = ((4 - j + 9) mod 9) + 1
         如果 diPan[pos] == null：
            diPan[pos] = 三奇[j]
   否则：
      对于 j 从 0 到 2：
         pos = ((4 + j - 1) mod 9) + 1
         如果 diPan[pos] == null：
            diPan[pos] = 三奇[j]
6. 返回 diPan
```

### 7.3 旬首计算算法

```
算法：CalculateXunShou
输入：时柱干支序号 k
输出：旬首信息

1. xunIndex = floor(k / 10)
2. k_xun = xunIndex * 10
3. jia = 六甲[xunIndex]
4. yi = 遁甲映射[jia]
5. 返回 (k_xun, jia, yi)
```

## 八、遁甲的周期分析

### 8.1 六甲周期

六甲值旬周期为60时辰（5天）。

### 8.2 遁甲周期

遁甲排布的完整周期为：

$$T_{\text{dunjia}} = \text{lcm}(60, 9) = 180 \text{ 时辰} = 15 \text{ 天}$$

### 8.3 与节气周期的复合

考虑节气周期（约365.25天）：

$$T_{\text{complete}} = \text{lcm}(15, 365.25) \approx 365.25 \text{ 天}$$

即每年遁甲排布模式基本重复，但存在微小漂移。

## 九、精度分析

### 9.1 遁甲映射的精确性

遁甲映射为离散对应，无精度损失。

### 9.2 排布计算的精确性

排布计算基于模运算，无舍入误差。

### 9.3 时辰边界处理

时辰以2小时为单位，边界处理需精确到分钟。

**建议**：使用儒略日数计算时辰，精度可达秒级。
