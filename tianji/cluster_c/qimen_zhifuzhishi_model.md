# 奇门遁甲值符值使计算模型

## 一、概念体系与数学定义

### 1.1 值符与值使的代数结构

奇门遁甲中的值符与值使构成一对对偶算子，分别对应天盘与地盘的核心驱动机制。设遁甲局数为 $G \in \{1, 2, \ldots, 18\}$，旬首为 $X \in \{0, 1, \ldots, 9\}$（以甲子为0），则值符与值使的确定可形式化为映射问题。

**定义（值符空间）**：值符空间 $\mathcal{F}$ 定义为九宫的幂集与天干集合的笛卡尔积：

$$\mathcal{F} = \mathcal{P}(\{1,2,\ldots,9\}) 	imes \{甲, 乙, 丙, \ldots, 壬, 癸\}$$

**定义（值使空间）**：值使空间 $\mathcal{M}$ 定义为九宫位置与八门状态的组合：

$$\mathcal{M} = \{1,2,\ldots,9\} 	imes \{休, 生, 伤, 杜, 景, 死, 惊, 开\}$$

### 1.2 旬首确定的模运算模型

给定干支历日期，设日干为 $D_g \in \{0, 1, \ldots, 9\}$（甲=0, 乙=1, ..., 癸=9），日支为 $D_z \in \{0, 1, \ldots, 11\}$（子=0, 丑=1, ..., 亥=11）。旬首的计算遵循以下算法：

**算法（旬首计算）**：

$$	ext{旬首索引} = \left\lfloor rac{D_g - D_z \mod 10}{10} ightfloor 	imes 10 + (D_g - D_z \mod 10)$$

等价地，采用更简洁的模运算表达：

$$X = (D_g - (D_z \mod 10) + 10) \mod 10$$

其中 $X = 0$ 对应甲子旬，$X = 1$ 对应甲戌旬，依此类推。

**定理（旬首唯一性）**：对于任意给定的日时组合，旬首的确定是唯一的。

*证明*：由于日干地支的组合在六十甲子循环中具有唯一性，而旬首将六十甲子划分为六个互不相交的子集（每旬10个干支），根据鸽巢原理，每个日时组合必然唯一属于某一旬。$\square$

## 二、值符落宫计算

### 2.1 基本计算公式

值符的落宫由旬首所对应的地盘六甲位置决定，再随局数进行位移变换。

**定义（地盘六甲位置）**：设地盘六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅）在九宫中的固定位置为映射 $L_0: \{0,1,2,3,4,5\} 	o \{1,2,\ldots,9\}$：

- 甲子（旬首0）：$L_0(0) = 1$（坎一宫）
- 甲戌（旬首1）：$L_0(1) = 6$（乾六宫）
- 甲申（旬首2）：$L_0(2) = 3$（震三宫）
- 甲午（旬首3）：$L_0(3) = 9$（离九宫）
- 甲辰（旬首4）：$L_0(4) = 4$（巽四宫）
- 甲寅（旬首5）：$L_0(5) = 7$（兑七宫）

**定理（值符落宫公式）**：设局数为 $G$，旬首索引为 $X \in \{0,1,\ldots,5\}$，则值符落宫 $P_f$ 为：

$$P_f = \phi_G(L_0(X))$$

其中 $\phi_G$ 为局数 $G$ 对应的宫位旋转变换。

对于阳遁，旋转变换为顺时针：

$$\phi_G^{	ext{阳}}(p) = ((p - 1 + G - 1) \mod 9) + 1$$

对于阴遁，旋转变换为逆时针：

$$\phi_G^{	ext{阴}}(p) = ((p - 1 - (G - 1)) \mod 9) + 1$$

### 2.2 值符随时的动态位移

值符落宫确定后，还需根据具体时辰进行动态调整。设当前时辰为 $t \in \{0, 1, \ldots, 11\}$（子=0, 丑=1, ..., 亥=11），则值符的实时位置为：

$$P_f(t) = \phi_{\Delta t}(P_f)$$

其中 $\Delta t = t - t_0$，$t_0$ 为旬首对应的起始时辰。

**引理（值符周期性）**：值符位置具有以12时辰为周期的循环特性。

*证明*：由于时辰循环周期为12，而九宫周期为9，根据最小公倍数原理，值符位置的复合周期为 $	ext{lcm}(12, 9) = 36$ 时辰。$\square$

## 三、值使落宫计算

### 3.1 值使与八门的对应关系

值使为值符所对应宫位的八门使者，其对应关系由固定的门宫配属决定：

**定义（门宫配属）**：八门与九宫的固定配属为映射 $D: \{休, 生, 伤, 杜, 景, 死, 惊, 开\} 	o \{1,2,\ldots,9\}$：

- 休门：坎一宫（1）
- 生门：艮八宫（8）
- 伤门：震三宫（3）
- 杜门：巽四宫（4）
- 景门：离九宫（9）
- 死门：坤二宫（2）
- 惊门：兑七宫（7）
- 开门：乾六宫（6）

**定理（值使确定定理）**：值使由值符落宫对应的八门唯一确定。

*证明*：设值符落宫为 $P_f$，则值使对应的八门 $M$ 满足 $D(M) = P_f$。由于 $D$ 是双射（除中五宫外），值使唯一确定。$\square$

### 3.2 值使运行轨迹的数学描述

值使在时辰推移中沿八门顺序运行，其轨迹可用离散动力系统描述。

**定义（八门循环序）**：八门的循环顺序为：

$$	ext{休} 	o 	ext{生} 	o 	ext{伤} 	o 	ext{杜} 	o 	ext{景} 	o 	ext{死} 	o 	ext{惊} 	o 	ext{开} 	o 	ext{休}$$

对应数值编码为：$0 	o 1 	o 2 	o 3 	o 4 	o 5 	o 6 	o 7 	o 0$

**定理（值使位移公式）**：设值使初始门编码为 $m_0$，经过 $k$ 个时辰后的值使门编码为：

$$m_k = (m_0 + k) \mod 8$$

对应的落宫为：

$$P_m(k) = D^{-1}(m_k)$$

### 3.3 值使落宫的完整算法

**算法（值使落宫计算）**：

输入：局数 $G$，旬首 $X$，当前时辰 $t$

1. 计算值符落宫：$P_f = \phi_G(L_0(X))$
2. 确定值使初始门：$m_0 = D^{-1}(P_f)$
3. 计算时辰偏移：$\Delta t = t - t_X$，其中 $t_X$ 为旬首起始时辰
4. 计算值使当前门：$m_t = (m_0 + \Delta t) \mod 8$
5. 输出值使落宫：$P_m(t) = D(m_t)$

## 四、值符值使的联合动力学

### 4.1 联合状态空间

值符与值使的联合状态可表示为二元组 $(P_f, P_m) \in \{1,\ldots,9\} 	imes \{1,\ldots,9\}$，但需排除中五宫（5）作为值符落宫的情况（因中五宫无八门配属）。

**定义（有效联合状态空间）**：

$$\mathcal{S}_{	ext{valid}} = \{(p_f, p_m) \in \{1,\ldots,9\}^2 : p_f 
eq 5 \land D^{-1}(p_f) 	ext{ 存在}\}$$

有效状态空间的大小为 $|\mathcal{S}_{	ext{valid}}| = 8 	imes 9 = 72$。

### 4.2 状态转移矩阵

值符值使的联合演化可表示为离散时间马尔可夫链，其状态转移矩阵 $T$ 为 $72 	imes 72$ 矩阵。

**定理（转移矩阵结构）**：状态转移矩阵 $T$ 具有块对角结构，每个块对应一个特定的局数和旬首组合。

*证明*：由于局数和旬首在排盘时固定，值符值使的演化在给定局数下是确定性的，因此转移矩阵每行只有一个非零元素（值为1），表现为置换矩阵的结构。$\square$

### 4.3 不动点分析

**定义（不动点）**：若存在状态 $(P_f^*, P_m^*)$ 使得经过12时辰后返回原状态，即：

$$(P_f(t+12), P_m(t+12)) = (P_f(t), P_m(t))$$

则称 $(P_f^*, P_m^*)$ 为系统的不动点。

**定理（不动点存在性）**：值符值使联合系统存在不动点当且仅当值符位置在12时辰周期内完成整数圈旋转。

*证明*：值符周期为36时辰（lcm(12,9)），值使周期为8时辰（八门循环）。联合周期为 $	ext{lcm}(36, 8) = 72$ 时辰。因此12时辰内返回原状态要求72整除12，显然不成立。故严格不动点不存在，但存在周期为72的极限环。$\square$

## 五、计算实例与验证

### 5.1 阳遁一局实例

**输入**：阳遁一局（$G=1$），甲子旬（$X=0$），子时（$t=0$）

**计算过程**：

1. 地盘甲子位置：$L_0(0) = 1$（坎一宫）
2. 值符落宫：$P_f = \phi_1^{	ext{阳}}(1) = ((1-1+1-1) \mod 9) + 1 = 1$
3. 值使初始门：$m_0 = D^{-1}(1) = 	ext{休门} = 0$
4. 时辰偏移：$\Delta t = 0 - 0 = 0$
5. 值使当前门：$m_0 = 0$，落宫 $P_m = D(0) = 1$

**输出**：值符落坎一宫，值使休门落坎一宫

### 5.2 阴遁九局实例

**输入**：阴遁九局（$G=9$），甲午旬（$X=3$），午时（$t=6$）

**计算过程**：

1. 地盘甲午位置：$L_0(3) = 9$（离九宫）
2. 值符落宫：$P_f = \phi_9^{	ext{阴}}(9) = ((9-1-(9-1)) \mod 9) + 1 = 1$
3. 值使初始门：$m_0 = D^{-1}(1) = 	ext{休门} = 0$
4. 旬首甲午对应午时，$\Delta t = 6 - 6 = 0$
5. 值使当前门：$m_0 = 0$，落宫 $P_m = 1$

**输出**：值符落坎一宫，值使休门落坎一宫

## 六、算法复杂度与优化

### 6.1 时间复杂度分析

值符值使计算算法的时间复杂度为 $O(1)$，因为所有运算均为常数时间的模运算和查表操作。

### 6.2 空间复杂度分析

空间复杂度为 $O(1)$，仅需存储固定的配属表（九宫八门映射、地盘六甲位置）。

### 6.3 向量化优化

对于批量排盘需求，可采用向量化运算：

$$\mathbf{P}_f = \phi_G(\mathbf{L}_0(\mathbf{X}))$$

其中向量运算通过NumPy等库实现，可显著提升大规模排盘效率。

## 七、误差分析与精度控制

### 7.1 边界条件处理

- 中五宫问题：值符不落中五宫，若计算结果为中五宫，需按"寄坤二宫"或"寄艮八宫"规则处理
- 时辰边界：跨日时辰需正确处理日期变更对旬首的影响

### 7.2 数值稳定性

模运算在整数域内进行，无浮点误差累积问题，算法具有完美的数值稳定性。
