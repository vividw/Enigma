# 六爻预测的概率模型

## 摘要

本文建立六爻预测的数学概率模型，将传统六爻占卜转化为可计算的概率推断问题。通过随机过程、贝叶斯推断和信息论，实现六爻预测的量化分析，为占卜结果的可靠性评估提供科学框架。

---

## 1. 六爻系统的概率空间

### 1.1 卦象的样本空间

六爻卦象由六个爻位组成，每爻有四种状态：

$$Y = \{老阴(6), 少阴(7), 少阳(8), 老阳(9)\}$$

本卦的样本空间大小：

$$|\Omega| = 4^6 = 4096$$

### 1.2 变卦的概率

老阴和老阳为变爻，变卦概率：

$$P(\text{变爻}) = P(6) + P(9)$$

设每爻出现概率相等：

$$P(6) = P(7) = P(8) = P(9) = \frac{1}{4}$$

则变爻概率：

$$P(\text{变爻}) = \frac{2}{4} = 0.5$$

k个变爻的概率：

$$P(k) = C_6^k \left(\frac{1}{2}\right)^6 = \frac{C_6^k}{64}$$

### 1.3 变卦空间

变卦数量取决于变爻数：

$$N_{change} = \sum_{k=0}^{6} C_6^k \cdot 2^k = 3^6 = 729$$

## 2. 起卦方法的概率分析

### 2.1 铜钱起卦

三枚铜钱，每枚正反面概率各0.5：

**结果概率分布**：

| 结果 | 组合数 | 概率 |
|-----|-------|-----|
| 老阴(6) | 1 | 1/8 |
| 少阴(7) | 3 | 3/8 |
| 少阳(8) | 3 | 3/8 |
| 老阳(9) | 1 | 1/8 |

### 2.2 时间起卦

以年月日时起卦，假设时间均匀分布：

$$P(\text{上卦}) = \frac{1}{8}, \quad P(\text{下卦}) = \frac{1}{8}$$

动爻位置：

$$P(\text{动爻}=k) = \frac{1}{6}, \quad k = 1, ..., 6$$

### 2.3 数字起卦

随机数起卦，假设均匀分布：

$$P(\text{卦象}) = \frac{1}{64}$$

## 3. 用神选取的概率模型

### 3.1 用神空间的定义

六爻用神包括：

- 世爻、应爻
- 六亲：父母、兄弟、子孙、妻财、官鬼
- 六神：青龙、朱雀、勾陈、螣蛇、白虎、玄武

用神空间：

$$|U| = 2 + 5 + 6 = 13$$

### 3.2 用神选取的条件概率

给定预测事项 $M$，用神 $U$ 的条件概率：

$$P(U|M) = \frac{P(M|U)P(U)}{P(M)}$$

**事项-用神映射表**：

- 求财：妻财爻
- 求官：官鬼爻
- 求学：父母爻
- 求子：子孙爻
- 竞争：兄弟爻

### 3.3 多用神情况

复杂事项可能涉及多个用神：

$$P(U_1, U_2 | M) = P(U_1 | M) \cdot P(U_2 | U_1, M)$$

## 4. 吉凶判断的概率框架

### 4.1 用神旺衰的概率

用神旺衰取决于：
- 月建：$P(\text{旺}|\text{月建})$
- 日辰：$P(\text{旺}|\text{日辰})$
- 动爻：$P(\text{旺}|\text{动爻生扶})$

综合旺衰概率：

$$P(\text{旺}) = 1 - \prod_{i}(1 - p_i)$$

### 4.2 吉凶的后验概率

给定卦象 $G$，结果 $R$ 的概率：

$$P(R|G) = \frac{P(G|R)P(R)}{P(G)}$$

### 4.3 预测置信度

预测置信度定义为后验概率的最大值：

$$Conf = \max_R P(R|G)$$

## 5. 贝叶斯推断模型

### 5.1 先验分布

结果的先验分布：

$$P(R = \text{吉}) = p_0$$

通常取 $p_0 = 0.5$（无信息先验）。

### 5.2 似然函数

给定结果，观测到卦象的似然：

$$P(G|R) = \prod_{i=1}^{6} P(y_i|R)$$

### 5.3 后验更新

观测到新卦象后更新信念：

$$P(R|G_{new}, G_{old}) = \frac{P(G_{new}|R)P(R|G_{old})}{P(G_{new}|G_{old})}$$

### 5.4 共轭先验

采用Beta分布作为先验：

$$P(p) = Beta(\alpha, \beta)$$

后验分布：

$$P(p|data) = Beta(\alpha + k, \beta + n - k)$$

## 6. 预测准确率分析

### 6.1 准确率的定义

在 $n$ 次预测中：

$$Accuracy = \frac{\text{正确预测次数}}{n}$$

### 6.2 准确率的置信区间

95%置信区间：

$$CI = \hat{p} \pm 1.96 \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

### 6.3 与随机猜测的比较

检验 $H_0: p = 0.5$ vs $H_1: p > 0.5$

检验统计量：

$$Z = \frac{\hat{p} - 0.5}{\sqrt{\frac{0.25}{n}}}$$

## 7. 信息论分析

### 7.1 卦象的信息熵

六爻卦象的熵：

$$H(G) = -\sum_{i=1}^{4096} p_i \log_2 p_i$$

均匀分布时：

$$H_{max} = \log_2 4096 = 12 \text{ bits}$$

### 7.2 互信息

卦象与结果的互信息：

$$I(G; R) = H(R) - H(R|G)$$

### 7.3 预测的信息增益

$$IG = H(R) - H(R|G)$$
