# 《开元占经》唐代占星典籍深度解析

## 一、版本源流与成书背景

### 1.1 作者与成书年代

《开元占经》是唐代瞿昙悉达奉敕编纂的大型占星学著作。

**瞿昙悉达**

瞿昙悉达，唐代天文学家：

- 印度裔中国人
- 曾任太史监
- 精通印度天文学

**成书背景**

《开元占经》成书于唐玄宗开元年间（713-741）：

- 奉敕编纂
- 集历代占星学之大成
- 为唐代占星学的官方典籍

### 1.2 版本流传

**唐代原本**

《开元占经》在唐代完成，共120卷。

**宋代流传**

宋代《开元占经》仍有流传，但已不完整。

**明代发现**

明代《开元占经》一度失传，后在民间发现抄本。

**清代整理**

清代《四库全书》收入《开元占经》，成为通行本。

### 1.3 现代版本

**《四库全书》本**

清代《四库全书》本是目前最通行的版本。

**现代校勘本**

现代学者对《开元占经》进行校勘整理：

- 中华书局本
- 其他校勘本

## 三、占星理论体系

### 3.1 天人感应理论

**基本原理**

《开元占经》的占星理论基础是天人感应：

- 天象变化预示人事吉凶
- 天人之间存在感应关系
- 通过观测天象预测人事

**感应机制**

天人感应的机制：

- 气感：天气与地气的感应
- 类应：同类事物的相应
- 数应：数字的对应关系

### 3.2 星占分类

**恒星占**

恒星的星占：

- 恒星的明暗
- 恒星的颜色
- 恒星的位置变化
- 新星的出現

**行星占**

行星的星占：

- 行星的位置
- 行星的运动
- 行星的会合
- 行星的变色

**日月占**

日月的星占：

- 日食
- 月食
- 日月变色
- 日月无光

**彗星占**

彗星的星占：

- 彗星的出现
- 彗星的形状
- 彗星的方向
- 彗星的移动

### 3.3 二十八宿占

**分野理论**

二十八宿与地上州国的对应：

- 角亢：郑、兖州
- 氐房心：宋、豫州
- 尾箕：燕、幽州
- 斗牛：吴、扬州
- 女虚危：齐、青州
- 室壁：卫、并州
- 奎娄：鲁、徐州
- 胃昴毕：赵、冀州
- 觜参：蜀、益州
- 井鬼：秦、雍州
- 柳星张：周、三河
- 翼轸：楚、荆州

**各宿星占**

各宿的星占意义：

- 角宿：主天门，为众星之长
- 亢宿：主朝廷，为疾病之宿
- 氐宿：主后宫，为根柢之宿
- 房宿：主天驷，为车驾之宿
- 心宿：主天王，为明堂之宿
- 尾宿：主后宫，为子孙之宿
- 箕宿：主口舌，为谗佞之宿
- 其他各宿各有其占

## 七、结语

《开元占经》是中国占星学史上的里程碑之作，其价值不仅在于其占星学知识的系统性和完整性，更在于其所保存的大量古代文献。从唐代到当代，《开元占经》一直是研究中国古代天文学和占星学的重要典籍。

从现代学术视角看，《开元占经》是理解中国古代占星学思维方式的重要文本。其所体现的占星理论、天文知识、文献价值，都是中华文明对人类文化宝库的重要贡献。

未来的《开元占经》研究，应当在文献考证的基础上，更多地关注其天文学内涵、文化意义和现代价值，在跨学科视野下推进对这一占星学经典的深入理解。
