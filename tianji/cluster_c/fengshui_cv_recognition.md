# 风水形势的计算机视觉识别

## 摘要

风水形势判断是风水实践的核心环节，传统方法依赖风水师的主观经验。本文将计算机视觉技术引入风水形势分析，建立山水形势的自动识别模型，量化风水要素的几何特征，为风水形势的客观化评估提供技术路径。

## 一、风水形势的形式化描述

### 1.1 形势的基本要素

风水形势由以下要素构成：

**龙脉（Mountain Range）**

龙脉是地形的骨架，形式化为曲线：

$$\mathcal{L}_{\text{龙}} = \{(x(t), y(t), z(t)) | t \in [0, 1]\}$$

**砂山（Protecting Hills）**

砂山是龙脉的护卫，形式化为曲面：

$$\mathcal{S}_{\text{砂}} = \{(x, y, z) | f(x, y, z) = 0\}$$

**水系（Water System）**

水系包括河流、湖泊等，形式化为曲线或曲面：

$$\mathcal{C}_{\text{水}} = \{(x(t), y(t)) | t \in [0, 1]\}$$

**穴位（Acupuncture Point）**

穴位是风水选址的核心位置：

$$P_{\text{穴}} = (x_0, y_0, z_0)$$

### 1.2 形势的数学特征

**龙脉的曲率**

龙脉的弯曲程度：

$$\kappa(t) = \frac{|\dot{x}\ddot{y} - \ddot{x}\dot{y}|}{(\dot{x}^2 + \dot{y}^2)^{3/2}}$$

**砂山的坡度**

砂山的倾斜程度：

$$\theta = \arctan\left(\frac{\partial z}{\partial r}\right)$$

其中 $r = \sqrt{x^2 + y^2}$

**水系的环抱度**

水系对穴位的环抱程度：

$$\gamma = \frac{\text{水系弧长}}{\text{穴位到水系距离}}$$

## 三、龙脉识别算法

### 3.1 山脊线提取

**基于DEM的方法**

从数字高程模型（DEM）提取山脊线：

**算法3.1（山脊线提取）**

输入：DEM数据 $Z(x, y)$
输出：山脊线集合 $\{\mathcal{L}_i\}$

1. 计算坡度：$S = \sqrt{(\frac{\partial Z}{\partial x})^2 + (\frac{\partial Z}{\partial y})^2}$
2. 计算坡向：$A = \arctan(\frac{\partial Z}{\partial y} / \frac{\partial Z}{\partial x})$
3. 提取山脊点：满足局部极大值且坡度大于阈值
4. 连接山脊点形成山脊线
5. 后处理：去噪、平滑、断线连接

**基于形态学的方法**

使用形态学运算提取地形特征：

- 顶帽变换：$T = I - (I \circ B)$
- 黑帽变换：$B = (I \bullet B) - I$

其中 $\circ$ 是开运算，$\bullet$ 是闭运算。

### 3.2 龙脉形态分析

**龙脉分类**

根据形态特征将龙脉分类：

- 生龙：起伏有致，生气勃勃
- 死龙：僵直无起伏
- 强龙：高大雄伟
- 弱龙：低矮无力
- 顺龙：顺势而下
- 逆龙：逆势而上

**形态特征量化**

**起伏度**

$$R = \frac{Z_{\max} - Z_{\min}}{L}$$

其中 $L$ 是龙脉长度。

**弯曲度**

$$C = \frac{L_{\text{实际}}}{L_{\text{直线}}}$$

**分支数**

$$N_{\text{分支}} = \text{龙脉的分支数量}$$

### 3.3 龙脉等级评估

**龙脉评分模型**

$$S_{\text{龙}} = w_1 \cdot R + w_2 \cdot C + w_3 \cdot N_{\text{分支}} + w_4 \cdot \text{连续性}$$

**龙脉等级**

- 祖龙：$S_{\text{龙}} \geq 0.9$
- 少祖龙：$0.8 \leq S_{\text{龙}} < 0.9$
- 父母龙：$0.7 \leq S_{\text{龙}} < 0.8$
- 枝龙：$S_{\text{龙}} < 0.7$

## 四、砂山识别算法

### 4.1 砂山检测

**基于高程的方法**

从DEM数据中提取砂山：

$$\mathcal{S}_{\text{砂}} = \{(x, y) | Z(x, y) > Z_{\text{阈值}} \land \text{Area}(x, y) > A_{\text{最小}}\}$$

**基于影像的方法**

使用遥感影像分类识别砂山：

**算法4.1（砂山分类）**

输入：遥感影像 $I$
输出：砂山掩膜 $M$

1. 特征提取：提取颜色、纹理、形状特征
2. 训练分类器：使用SVM或Random Forest
3. 像素分类：对每个像素进行分类
4. 后处理：形态学滤波、连通域分析
5. 输出砂山掩膜

### 4.2 砂山方位判定
n
砂山相对于穴位的方位：

$$\theta = \arctan\left(\frac{y_{\text{砂}} - y_{\text{穴}}}{x_{\text{砂}} - x_{\text{穴}}}\right)$$

**四象砂山**

- 左青龙：$\theta \in [45°, 135°]$
- 右白虎：$\theta \in [225°, 315°]$
- 前朱雀：$\theta \in [135°, 225°]$
- 后玄武：$\theta \in [315°, 45°]$（含0°）

### 4.3 砂山形态评估

**青龙砂评估**

$$S_{\text{青龙}} = w_1 \cdot \text{高度} + w_2 \cdot \text{长度} + w_3 \cdot \text{弯曲度} + w_4 \cdot \text{距离}$$

理想青龙砂：
- 高度适中：略高于穴位
- 长度足够：延伸较远
- 弯曲有情：环抱穴位
- 距离适当：不过近也不过远

**白虎砂评估**

白虎砂的要求与青龙砂类似，但高度略低于青龙砂：

$$H_{\text{白虎}} \approx 0.8 \cdot H_{\text{青龙}}$$

## 五、水系识别算法

### 5.1 水体提取

**基于光谱的方法**

利用水体的光谱特性提取：

**归一化水体指数（NDWI）**

$$\text{NDWI} = \frac{\text{GREEN} - \text{NIR}}{\text{GREEN} + \text{NIR}}$$

水体像素：$\text{NDWI} > \text{阈值}$

**改进的归一化水体指数（MNDWI）**

$$\text{MNDWI} = \frac{\text{GREEN} - \text{MIR}}{\text{GREEN} + \text{MIR}}$$

**基于深度学习的方法**

使用U-Net进行水体分割：

**算法5.1（水体分割）**

输入：遥感影像 $I$
输出：水体掩膜 $M$

1. 数据准备：标注训练样本
2. 网络训练：训练U-Net模型
3. 推理预测：对新影像进行分割
4. 后处理：去除小斑块、填充孔洞
5. 输出水体掩膜

### 5.2 水系形态分析

**河流中心线提取**

使用骨架化算法提取河流中心线：

$$\mathcal{C}_{\text{河}} = \text{Skeletonize}(M_{\text{水}})$$

**河流弯曲度**

$$\text{弯曲度} = \frac{L_{\text{实际}}}{L_{\text{直线}}}$$

**河流环抱度**

$$\text{环抱度} = \frac{\text{穴位到河流的平均距离}}{\text{河流曲率半径}}$$

### 5.3 水口识别

**水口定义**

水口是水流汇聚或流出的位置：

$$P_{\text{水口}} = \arg\min_{P} \sum_{i} d(P, \mathcal{C}_i)$$

其中 $\mathcal{C}_i$ 是各条河流的中心线。

**水口形态分类**

- 交锁水口：多条河流交汇
- 紧闭水口：水口狭窄
- 开阔水口：水口宽阔

## 六、穴位识别算法

### 6.1 穴位候选点生成

**基于地形的方法**

穴位通常位于地形的关键位置：

**算法6.1（穴位候选点生成）**

输入：DEM数据 $Z(x, y)$
输出：穴位候选点集合 $\{P_i\}$

1. 提取地形特征点：山脊交点、山谷交点
2. 计算地形曲率：$K = \frac{\partial^2 Z}{\partial x^2} + \frac{\partial^2 Z}{\partial y^2}$
3. 选择曲率变化点：$|\nabla K| > \text{阈值}$
4. 筛选候选点：坡度适中、朝向良好
5. 输出候选点集合

**基于龙脉的方法**

穴位位于龙脉的关键节点：

- 龙脉的起、止、转、折处
- 龙脉的分支点
- 龙脉的聚结处

### 6.2 穴位评估

**穴位评分模型**

$$S_{\text{穴}} = \sum_{i} w_i \cdot f_i(P)$$

其中 $f_i$ 是各项评估指标：

- $f_1$：龙脉质量
- $f_2$：砂山配置
- $f_3$：水系环抱
- $f_4$：朝向方位
- $f_5$：地形平整度

**穴位等级**

- 上等穴：$S_{\text{穴}} \geq 0.85$
- 中等穴：$0.70 \leq S_{\text{穴}} < 0.85$
- 下等穴：$S_{\text{穴}} < 0.70$

### 7.2 应用案例

**案例：某山地风水评估**

**数据准备**

- DEM：30米分辨率
- 影像：Landsat 8 OLI
- 区域：10km × 10km

**处理流程**

1. 龙脉提取：识别主龙脉3条，支龙脉12条
2. 砂山识别：识别左青龙砂5座，右白虎砂4座
3. 水系提取：识别河流2条，湖泊1个
4. 穴位评估：生成候选点20个，评估出上等穴3个

**评估结果**

- 最佳穴位坐标：(X, Y, Z)
- 龙脉评分：0.88
- 砂山评分：0.82
- 水系评分：0.85
- 综合评分：0.85（上等穴）
