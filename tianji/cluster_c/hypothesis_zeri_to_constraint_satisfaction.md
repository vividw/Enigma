# 假说：择日与约束满足问题的对应

## 1. 假说陈述

**核心假说**：中国传统择日学中的吉日选择问题可严格映射为计算机科学中的约束满足问题（CSP）。择日中的各种规则（黄道、建除、冲煞、五行等）对应CSP中的约束条件，而吉日选择对应CSP的求解过程。

## 2. 理论依据

### 2.1 CSP的基本定义

约束满足问题由三元组 $(X, D, C)$ 定义：
- $X = \{x_1, \ldots, x_n\}$：变量集合
- $D = \{D_1, \ldots, D_n\}$：值域集合
- $C = \{c_1, \ldots, c_m\}$：约束集合

### 2.2 择日的CSP映射

**假说2.1**：择日问题可映射为CSP：

- 变量：年柱、月柱、日柱、时柱
- 值域：各柱的可能取值（60甲子）
- 约束：黄道、建除、冲煞、五行等规则

### 2.3 约束的类型对应

| 择日规则 | CSP约束类型 |
|---------|------------|
| 黄道吉日 | 一元约束 |
| 干支配对 | 二元约束 |
| 五行平衡 | 全局约束 |
| 冲煞规避 | 否定约束 |

## 3. 预测与验证

### 3.1 可检验预测

**预测1**：择日问题的求解复杂度为NP完全，与理论CSP复杂度一致。

**预测2**：约束传播算法（如AC-3）可有效减少择日的搜索空间。

**预测3**：启发式方法（如MRV）可加速择日求解。

## 4. 数学推导

### 4.1 择日CSP的形式化

$$X = \{G_Y, Z_Y, G_M, Z_M, G_D, Z_D, G_H, Z_H\}$$

$$c_{干支}: G \equiv Z \pmod{2}$$

$$c_{黄道}: (Z_D, J) \notin R_{黑道}$$

### 4.2 复杂度分析

一般CSP是NP完全的。

择日CSP的特殊结构：
- 变量域大小：60（甲子）
- 约束图稀疏
- 存在层次结构

### 4.3 算法复杂度

回溯算法最坏复杂度：$O(d^n)$

约束传播后：$O(d^{n'})$，$n' < n$
