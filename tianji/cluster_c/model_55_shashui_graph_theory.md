# 砂水格局的图论表示

## 1. 砂水格局的图抽象

风水砂水格局描述穴位周围山砂与水系的配置关系。从图论视角，砂水格局可抽象为带权图，其中节点代表砂水要素，边代表空间关系。

### 1.1 图的基本定义

砂水图 $G = (V, E)$ 包含：

**节点集** $V = V_{sha} \cup V_{shui}$：
- $V_{sha}$：砂（山丘、高地）节点
- $V_{shui}$：水（河流、湖泊）节点

**边集** $E \subseteq V \times V$：
- 空间邻接关系
- 视线连通关系
- 气流/水流通道

### 1.2 节点属性

每个节点 $v \in V$ 具有属性向量：

$$\vec{a}(v) = (x_v, y_v, z_v, t_v, s_v, \ldots)$$

其中：
- $(x_v, y_v, z_v)$：空间坐标
- $t_v \in \{sha, shui\}$：节点类型
- $s_v$：规模/重要性度量

### 1.3 边权重

边 $(u,v) \in E$ 的权重：

$$w(u,v) = f(d(u,v), \theta_{uv}, \phi_{uv})$$

其中：
- $d(u,v) = \sqrt{(x_u-x_v)^2 + (y_u-y_v)^2 + (z_u-z_v)^2}$：欧氏距离
- $\theta_{uv}$：相对方位角
- $\phi_{uv}$：相对仰角

## 2. 砂水图的矩阵表示

### 2.1 邻接矩阵

砂水图的邻接矩阵 $A \in \mathbb{R}^{|V| \times |V|}$：

$$A_{ij} = \begin{cases} w(v_i, v_j) & \text{if } (v_i, v_j) \in E \\ 0 & \text{otherwise} \end{cases}$$

### 2.2 度矩阵

节点度矩阵 $D$ 为对角矩阵：

$$D_{ii} = \sum_j A_{ij}$$

### 2.3 Laplacian矩阵

图Laplacian：

$$L = D - A$$

归一化Laplacian：

$$\mathcal{L} = D^{-1/2}LD^{-1/2} = I - D^{-1/2}AD^{-1/2}$$

## 3. 砂水图的谱分析

### 3.1 特征值与图结构

Laplacian特征值 $0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n$ 的图论意义：

- $\lambda_2$：代数连通度（Fiedler值）
- $\lambda_n$：最大度上界
- 特征值分布：图的整体连通性

### 3.2 Fiedler向量

对应 $\lambda_2$ 的特征向量 $\vec{v}_2$ 称为Fiedler向量，用于图分割：

$$V_+ = \{v_i : v_{2,i} > 0\}, \quad V_- = \{v_i : v_{2,i} < 0\}$$

### 3.3 谱聚类

基于Laplacian谱的砂水格局聚类：

1. 计算前 $k$ 个特征向量
2. 节点映射到谱空间
3. K-means聚类
4. 得到 $k$ 个砂水功能区

## 4. 砂水图的中心性分析

### 4.1 度中心性

节点度中心性：

$$C_D(v) = \frac{\deg(v)}{|V| - 1}$$

高度中心性节点为砂水格局的关键要素。

### 4.2 介数中心性

节点介数中心性：

$$C_B(v) = \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$

其中 $\sigma_{st}$ 为 $s$ 到 $t$ 的最短路径数，$\sigma_{st}(v)$ 为经过 $v$ 的路径数。

### 4.3 特征向量中心性

节点特征向量中心性满足：

$$C_E(v) = \frac{1}{\lambda}\sum_{u \in N(v)} C_E(u)$$

即邻接矩阵主特征向量的分量。

### 4.4 PageRank中心性

PageRank值：

$$PR(v) = \frac{1-d}{|V|} + d\sum_{u \in N_{in}(v)} \frac{PR(u)}{|N_{out}(u)|}$$

其中 $d$ 为阻尼因子。

## 5. 砂水格局的社区检测

### 5.1 模块度

社区划分的模块度：

$$Q = \frac{1}{2m}\sum_{ij}\left(A_{ij} - \frac{k_i k_j}{2m}\right)\delta(c_i, c_j)$$

其中 $m = \frac{1}{2}\sum_{ij}A_{ij}$，$c_i$ 为节点 $i$ 的社区标签。

### 5.2 Louvain算法

贪心优化模块度的社区检测：

1. 每个节点独立成社区
2. 迭代合并增加模块度的社区对
3. 构建凝聚图重复步骤2
4. 直至模块度不再增加

### 5.3 砂水功能区识别

社区检测识别砂水格局的功能区：

- 龙脉社区（山系连通分量）
- 水系社区（河流网络）
- 明堂社区（砂水交汇区）

## 6. 砂水图的演化模型

### 6.1 随机图模型

Erdos-Renyi模型：

$$G(n, p): \quad P((i,j) \in E) = p$$

### 6.2 小世界网络

Watts-Strogatz模型：

1. 从规则格点开始
2. 以概率 $p$ 重连边
3. 产生高聚类、短路径特性

### 6.3 无标度网络

Barabasi-Albert模型：

1. 初始 $m_0$ 个节点
2. 每步添加新节点，优先连接到高度数节点
3. 产生幂律度分布

## 7. 砂水格局的优化设计

### 7.1 目标函数

优化砂水图以满足风水要求：

$$\max_G f(G) = w_1 \lambda_2(G) + w_2 Q(G) + w_3 C(G)$$

其中：
- $\lambda_2$：代数连通度（整体连通性）
- $Q$：模块度（功能区清晰）
- $C$：中心性集中度（有核心要素）

### 7.2 图编辑操作

允许的图修改操作：

- 添加/删除节点（增删砂水要素）
- 添加/删除边（改变空间关系）
- 修改边权重（调整影响强度）

### 7.3 模拟退火优化

图优化算法：

1. 初始随机图
2. 随机图编辑产生新图
3. 以概率 $\min(1, e^{\Delta f/T})$ 接受
4. 降温重复步骤2-3

## 8. 结论

图论为砂水格局分析提供了强大的数学工具。邻接矩阵、Laplacian谱、中心性、社区检测等概念与风水中的"砂环水抱"、"藏风聚气"等理念建立了精确的对应关系。该模型可用于风水格局的定量评估、优化设计和自动识别。
