# 干支纪年与公历转换算法

## 一、问题定义

干支纪年与公历（格里高利历）的相互转换是术数计算中最基础且频繁使用的操作。本节建立严格的数学映射关系，推导高精度转换算法，并分析各种边界条件下的处理策略。

## 二、历法基础

### 2.1 公历结构

公历（格里高利历）定义：

- 平年：365天
- 闰年：366天（2月29天）

**闰年判定规则**：

$$\text{闰年} \iff (Y \bmod 4 = 0) \land ((Y \bmod 100 \neq 0) \lor (Y \bmod 400 = 0))$$

### 2.2 干支纪年结构

干支纪年以60年为周期，每年对应一个甲子组合。

**基准点**：公元1984年为甲子年（第0个甲子）。

### 2.3 春节问题

干支纪年以农历正月初一为分界，而非公历1月1日。

设 $L(Y)$ 为公历年份 $Y$ 的春节日期（儒略日），则：

- 公历日期 $< L(Y)$：属上一年干支
- 公历日期 $\geq L(Y)$：属当年干支

## 三、公历到干支的转换算法

### 3.1 年份转换（忽略春节）

**基本公式**：

$$k = (Y - 4) \bmod 60$$

**推导**：

已知1984年为甲子年（$k = 0$）。

设基准年份 $Y_0 = 1984$，则：

$$k = (Y - Y_0) \bmod 60 = (Y - 1984) \bmod 60$$

简化：$1984 \bmod 60 = 4$，故：

$$k = (Y - 4) \bmod 60$$

### 3.2 天干地支提取

$$t = k \bmod 10$$

$$d = k \bmod 12$$

### 3.3 完整日期转换算法

```
算法：GregorianToGanzhi
输入：公历日期 (year, month, day)
输出：干支年、干支月、干支日

1. 计算春节日期 L = ChineseNewYear(year)
2. 如果 (month, day) < L：
   a. 干支年序号 k_year = (year - 1 - 4) mod 60
   否则：
   b. 干支年序号 k_year = (year - 4) mod 60
3. 提取年天干 t_y = k_year mod 10
   提取年地支 d_y = k_year mod 12
4. 计算干支月（见下文）
5. 计算干支日（见下文）
6. 返回结果
```

### 3.4 春节日期计算

春节为农历正月初一，其公历日期在1月21日至2月20日之间波动。

**高精度算法**（基于天文计算）：

农历以朔日（新月）为月首，春节为冬至后的第二个朔日（或闰月调整后的第一个朔日）。

简化算法（1900-2100年适用）：

```
算法：ChineseNewYear
输入：公历年份 Y
输出：春节的公历日期 (month, day)

1. 基础日期计算：
   n = Y - 1900
   g = 4.6296 + 0.2422 * n - floor(n / 4)
2. 调整项：
   根据1900-2100年的观测数据查表或使用插值公式
3. 返回 (1 或 2, day)
```

### 3.5 月干支计算

**月建规则**：

- 正月建寅（地支为寅）
- 月地支按顺序递推

**月天干规则**（五虎遁）：

年天干决定正月的起始天干：

- 甲己之年：正月起丙寅
- 乙庚之年：正月起戊寅
- 丙辛之年：正月起庚寅
- 丁壬之年：正月起壬寅
- 戊癸之年：正月起甲寅

**数学表达**：

设年天干为 $t_y$，则正月天干为：

$$t_{m1} = (2t_y + 2) \bmod 10$$

第 $n$ 个月（正月 $n=1$）的天干为：

$$t_m = (t_{m1} + n - 1) \bmod 10$$

地支为：

$$d_m = (2 + n - 1) \bmod 12 = (n + 1) \bmod 12$$

### 3.6 日干支计算

**基准点**：1900年1月31日为甲辰日（序号40）。

**算法**：

计算从基准点到目标日期的天数差 $\Delta d$。

日干支序号：

$$k_d = (40 + \Delta d) \bmod 60$$

**天数差计算**：

```
算法：DaysBetween
输入：日期 d1, d2
输出：天数差

1. 将两日期转换为儒略日数 JD1, JD2
2. 返回 JD2 - JD1
```

儒略日数计算（格里高利历）：

$$JD = \lfloor 365.25(y + 4716) \rfloor + \lfloor 30.6001(m + 1) \rfloor + d + b - 1524.5$$

其中：
- 若 $m \leq 2$，则 $y = Y - 1, m = M + 12$，否则 $y = Y, m = M$
- $b = 2 - \lfloor y/100 \rfloor + \lfloor y/400 \rfloor$（格里高利历修正）

## 四、干支到公历的转换算法

### 4.1 年干支到公历年份

给定甲子序号 $k$，对应的公历年份为：

$$Y = 4 + k + 60n$$

其中 $n$ 为整数，使得 $Y$ 落在目标范围内。

**示例**：求庚子年对应的公历年份

$$k = 36$$（庚=6，子=0，$k = 6 \times 6 - 5 \times 0 = 36$）

$$Y = 4 + 36 + 60n = 40 + 60n$$

近年的庚子年：
- $n = 32$：$Y = 40 + 1920 = 1960$
- $n = 33$：$Y = 40 + 1980 = 2020$
- $n = 34$：$Y = 40 + 2040 = 2080$

### 4.2 月干支到公历月份

月干支到公历月份的转换需要结合年干支和春节日期。

**算法**：

```
算法：GanzhiMonthToGregorian
输入：年干支 k_y，月干支 (t_m, d_m)
输出：公历月份范围

1. 根据年天干确定正月天干 t_m1
2. 计算月序号 n = (d_m - 2) mod 12 + 1
3. 验证天干匹配：t_m ?= (t_m1 + n - 1) mod 10
4. 根据春节日期 L 和农历月长度确定公历范围
5. 返回结果
```

### 4.3 日干支到公历日期

**算法**：

```
算法：GanzhiDayToGregorian
输入：日干支 k_d，目标年份范围
输出：公历日期列表

1. 计算基准日 JD0 = 1900年1月31日
2. 对于目标范围内的每个候选年份：
   a. 计算该年的所有 k_d 对应的儒略日
   b. JD = JD0 + k_d - 40 + 60n（n为整数）
   c. 将 JD 转换回公历日期
3. 返回所有匹配日期
```

## 五、高精度计算

### 5.1 儒略日数的精度

儒略日数的整数部分可精确表示日期，小数部分表示日内时间。

对于干支计算，仅需整数部分：

$$JD_{\text{整数}} = \lfloor JD + 0.5 \rfloor$$

### 5.2 农历计算的精度挑战

农历以朔望月（约29.53天）和回归年（约365.2422天）为基础，存在周期性误差累积。

**朔望月长度**：

$$T_{\text{synodic}} = 29.53058867 \text{ 天}$$

**回归年长度**：

$$T_{\text{tropical}} = 365.24219052 \text{ 天}$$

**误差分析**：

使用固定朔望月长度计算，每世纪累积误差约0.1天。

### 5.3 节气计算的精度

节气基于太阳黄经，每个节气间隔约15度。

**节气时刻计算**：

$$T_{\text{节气}} = T_{\text{基准}} + n \times 15.218425 \text{ 天}$$

其中 $n$ 为节气序号。

## 六、算法复杂度分析

### 6.1 时间复杂度

- 年份转换：$O(1)$
- 完整日期转换（含春节计算）：$O(1)$（使用查表或近似公式）
- 日干支转换：$O(1)$（儒略日计算）

### 6.2 空间复杂度

- 基础算法：$O(1)$
- 查表法（1900-2100年春节）：$O(200)$ 字节

## 七、精度验证

### 7.1 边界测试用例

**测试1**：1984年春节（2月2日）

- 1月1日-2月1日：癸亥年
- 2月2日起：甲子年

**测试2**：闰年边界

2000年为闰年（能被400整除），2月有29天。

**测试3**：世纪边界

1900年不是闰年（能被100但不能被400整除）。

### 7.2 周期验证

验证60年周期：

$$k(Y + 60) = (Y + 60 - 4) \bmod 60 = (Y - 4) \bmod 60 = k(Y)$$

周期验证通过。

## 八、应用示例

### 8.1 计算2024年6月1日的干支

**年干支**：

2024年春节为2月10日，6月1日已过春节。

$$k_{year} = (2024 - 4) \bmod 60 = 2020 \bmod 60 = 40$$

$$t = 40 \bmod 10 = 0 \Rightarrow 甲$$

$$d = 40 \bmod 12 = 4 \Rightarrow 辰$$

年干支：甲辰

**月干支**：

年天干为甲，正月起丙寅。

6月为农历四月（正月=1，二月=2，...，四月=4）。

月天干：$(2 + 4 - 1) \bmod 10 = 5 \Rightarrow 己$

月地支：$(2 + 4 - 1) \bmod 12 = 5 \Rightarrow 巳$

月干支：己巳

**日干支**：

计算从1900年1月31日到2024年6月1日的天数。

使用儒略日公式：

JD(1900, 1, 31) = 2415079.5

JD(2024, 6, 1) = 2460451.5

天数差：$2460451.5 - 2415079.5 = 45372$

日干支序号：$(40 + 45372) \bmod 60 = 45412 \bmod 60 = 52$

$$t = 52 \bmod 10 = 2 \Rightarrow 丙$$

$$d = 52 \bmod 12 = 4 \Rightarrow 辰$$

日干支：丙辰

### 8.2 反查庚子年对应公历年份

$$k = 36$$

$$Y = 4 + 36 + 60n = 40 + 60n$$

20世纪的庚子年：

$$n = 31: Y = 40 + 1860 = 1900$$

$$n = 32: Y = 40 + 1920 = 1960$$

21世纪的庚子年：

$$n = 33: Y = 40 + 1980 = 2020$$

$$n = 34: Y = 40 + 2040 = 2080$$

## 九、可衍生研究方向

### 9.1 假设生成：历法转换到时间序列分析的映射

干支纪年可视为周期为60的离散时间序列，可应用傅里叶分析、小波变换等现代信号处理技术。

### 9.2 假设生成：历法转换到历法密码学的映射

干支纪年的周期性结构可设计为流密码的伪随机数生成器，其60阶循环群的代数性质提供安全性基础。
