# 面部特征点的几何分析

## 1. 面部特征点的数学抽象

面相学中的面部特征可抽象为三维空间中的点集，通过几何分析可以量化面部特征，为面相判断提供数学基础。

### 1.1 面部坐标系

建立面部坐标系：

**原点**：两眉中点（眉心）

**x轴**：水平向右（从左耳到右耳）

**y轴**：垂直向上（从下巴到额头）

**z轴**：垂直于面部平面向外

### 1.2 特征点定义

定义68个面部特征点（基于iBUG标准）：

**轮廓点**：$P_1, P_2, \ldots, P_{17}$（下巴到眉毛）

**眉毛点**：$P_{18}, \ldots, P_{27}$（左右眉毛）

**鼻子点**：$P_{28}, \ldots, P_{36}$（鼻梁到鼻尖）

**眼睛点**：$P_{37}, \ldots, P_{48}$（左右眼睛）

**嘴巴点**：$P_{49}, \ldots, P_{68}$（嘴唇轮廓）

### 1.3 特征点坐标

每个特征点 $P_i = (x_i, y_i, z_i) \in \mathbb{R}^3$

面部特征点集：$\mathcal{P} = \{P_1, P_2, \ldots, P_{68}\}$

## 2. 面部几何度量

### 2.1 距离度量

**欧氏距离**：

$$d(P_i, P_j) = \sqrt{(x_i-x_j)^2 + (y_i-y_j)^2 + (z_i-z_j)^2}$$

**面部宽度**：$W_{face} = d(P_1, P_{17})$

**面部高度**：$H_{face} = d(P_9, P_{28})$

### 2.2 角度度量

**三点夹角**：

$$\theta(P_i, P_j, P_k) = \arccos\frac{(P_i-P_j)\cdot(P_k-P_j)}{|P_i-P_j||P_k-P_j|}$$

**面部角度特征**：

- 下颌角：$\theta(P_3, P_9, P_{15})$
- 眉弓角：$\theta(P_{18}, P_{22}, P_{27})$
- 鼻唇角：$\theta(P_{34}, P_{52}, P_{58})$

### 2.3 曲率度量

面部轮廓的曲率：

$$\kappa(s) = \frac{|\vec{r}'(s) \times \vec{r}''(s)|}{|\vec{r}'(s)|^3}$$

其中 $\vec{r}(s)$ 为轮廓曲线的弧长参数化。

## 3. 面部对称性分析

### 3.1 对称平面

面部对称平面通过眉心，垂直于x轴：

$$\Pi_{sym}: x = 0$$

### 3.2 对称性度量

**点对称误差**：

$$\epsilon_{sym} = \frac{1}{n}\sum_{i=1}^{n} |d(P_i, \Pi_{sym}) - d(P_i', \Pi_{sym})|$$

其中 $P_i'$ 为 $P_i$ 关于对称平面的镜像点。

### 3.3 对称性评分

$$S_{sym} = 1 - \frac{\epsilon_{sym}}{\epsilon_{max}}$$

对称性越高，$S_{sym}$ 越接近1。

## 4. 面部比例分析

### 4.1 三停比例

**上停**：发际到眉心 $H_1 = y_{hairline} - y_{brow}$

**中停**：眉心到鼻底 $H_2 = y_{brow} - y_{nose}$

**下停**：鼻底到下巴 $H_3 = y_{nose} - y_{chin}$

三停比例：$R_{三停} = (H_1 : H_2 : H_3)$

### 4.2 五眼比例

面部宽度分为五等份，每份约等于一眼宽度：

$$W_{eye} = \frac{W_{face}}{5}$$

两眼间距：$d_{eye} = d(P_{40}, P_{43})$

五眼比例符合度：

$$C_{五眼} = 1 - \frac{|d_{eye} - W_{eye}|}{W_{eye}}$$

### 4.3 黄金比例

面部黄金比例点：

$$\phi = \frac{1+\sqrt{5}}{2} \approx 1.618$$

黄金比例符合度：

$$G = \frac{1}{n}\sum_{i} \left(1 - \frac{|r_i - \phi|}{\phi}\right)$$

## 5. 面部形状分类

### 5.1 形状特征向量

提取面部形状特征：

$$\vec{f} = (W_{face}, H_{face}, \kappa_{jaw}, S_{sym}, R_{三停}, C_{五眼})$$

### 5.2 聚类分析

使用K-means聚类将面部分为若干类型：

$$\min_{\mu_1, \ldots, \mu_k} \sum_{i=1}^{k} \sum_{\vec{f} \in C_i} |\vec{f} - \mu_i|^2$$

### 5.3 形状分类

- 圆形脸：$W_{face} \approx H_{face}$，$\kappa_{jaw}$ 大
- 方形脸：$W_{face} \approx H_{face}$，$\kappa_{jaw}$ 小
- 长形脸：$H_{face} > W_{face}$
- 心形脸：$W_{forehead} > W_{jaw}$

## 6. 面部特征点的统计模型

### 6.1 主成分分析

对特征点集进行PCA：

$$\vec{P} = \vec{\mu} + \sum_{i=1}^{k} \alpha_i \vec{e}_i$$

其中 $\vec{e}_i$ 为主成分方向，$\alpha_i$ 为形状参数。

### 6.2 形状空间

面部形状构成低维流形：

$$\mathcal{M} = \{\vec{\mu} + E\vec{\alpha} : \vec{\alpha} \in \mathbb{R}^k\}$$

### 6.3 形状变化模型

形状变化沿主成分方向：

$$\vec{P}(\alpha) = \vec{\mu} + \alpha \vec{e}_1$$

## 7. 面部特征检测算法

### 7.1 基于模型的检测

主动形状模型（ASM）：

1. 初始化形状模型
2. 搜索边缘点
3. 更新形状参数
4. 迭代收敛

### 7.2 基于学习的检测

深度学习方法：

- 输入：面部图像
- 输出：68个特征点坐标
- 损失函数：$L = \sum_{i=1}^{68} |P_i^{pred} - P_i^{true}|^2$

### 7.3 检测精度评估

**归一化平均误差**：

$$NME = \frac{1}{68}\sum_{i=1}^{68} \frac{|P_i^{pred} - P_i^{true}|}{d_{interocular}}$$

## 8. 结论

几何分析为面相学提供了量化的数学工具。特征点、距离、角度、曲率、对称性等概念与面相学中的面部特征描述建立了精确的对应关系。该模型可用于面部特征的自动检测和分析，为面相判断提供客观依据。
