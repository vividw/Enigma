# 杭辛斋学术图谱考据

## 一、人物生平概览

**生卒年份**：公元1869年-1924年，享年55岁

**籍贯考辨**：浙江海宁（今浙江海宁市）人，字慎修，号夷吾。海宁地处浙北，是近代文化发达的地区之一。

**时代背景**：杭辛斋生活于中国近代，正值社会剧变时期。此时期传统学术面临西学冲击，学者开始探索中西学术的融合。

**革命经历**：杭辛斋早年投身革命，参加同盟会，从事反清活动。

**学术转变**：辛亥革命后，专心学术研究，致力于易学研究。

**学术特点**：杭辛斋治学注重易学与现实的结合，是近代义理派易学的代表人物。

## 二、学术突破与理论创新

### 2.1 易学研究的贡献

杭辛斋在易学领域有重要贡献：

**《易学丛书》**：

- 收录杭辛斋的易学著作
- 体现其易学思想
- 对近代易学有重要影响

**易学思想**：

- 注重易学的义理研究
- 强调易学与现实的结合
- 主张易学为社会服务

### 2.2 易学与革命

杭辛斋将易学与革命思想相结合：

- 以易学解释革命的必要性
- 以易学论证共和的合理性
- 体现易学经世致用的传统

### 2.3 与术数的关系

杭辛斋作为易学家，对术数有复杂态度：

**对义理之学的重视**：

- 重视易学的义理研究
- 反对将易学神秘化
- 主张从哲学角度理解易学

**对术数的批判**：

- 批评将易学用于迷信
- 主张易学的理性化
- 区分学术研究与迷信

### 2.4 与同时代学者的比较

与尚秉和的比较：

- 杭辛斋偏重义理，尚秉和偏重象数
- 杭辛斋注重哲学，尚秉和注重筮法
- 二人代表了近代易学的不同方向
