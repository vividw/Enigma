# 通书编排的组合优化

## 1. 通书编排的数学模型

通书（黄历）编排是将大量择日信息组织成可查阅格式的组合优化问题。通过定义信息单元、版面约束和优化目标，可以实现通书的自动编排。

### 1.1 信息单元的定义

通书信息单元集合 $I = \{i_1, i_2, \ldots, i_n\}$，每个单元具有属性：

$$attr(i) = (type, size, priority, dependencies)$$

其中：
- $type$：信息类型（宜、忌、神煞、时辰等）
- $size$：占用版面大小
- $priority$：显示优先级
- $dependencies$：依赖的其他信息单元

### 1.2 版面空间模型

版面空间离散化为网格：

$$S = \{(x, y) : x \in \{1, \ldots, W\}, y \in \{1, \ldots, H\}\}$$

其中 $W$ 为版面宽度，$H$ 为版面高度。

### 1.3 布局变量

布局为信息单元到位置的映射：

$$L: I \to 2^S$$

其中 $L(i) \subseteq S$ 为单元 $i$ 占用的网格集合。

## 2. 通书编排的约束条件

### 2.1 非重叠约束

任意两个信息单元不重叠：

$$\forall i \neq j: L(i) \cap L(j) = \emptyset$$

### 2.2 边界约束

信息单元必须在版面内：

$$\forall i: L(i) \subseteq S$$

### 2.3 相邻约束

相关单元应相邻显示：

$$\forall (i, j) \in E_{adj}: d(L(i), L(j)) \leq d_{max}$$

其中 $d$ 为单元间距离。

### 2.4 优先级约束

高优先级单元优先放置：

$$priority(i) > priority(j) \Rightarrow y_i \leq y_j$$

## 3. 优化目标函数

### 3.1 版面利用率

$$f_1(L) = \frac{|\bigcup_i L(i)|}{|S|}$$

### 3.2 信息完整性

$$f_2(L) = \frac{|\{i \in I : L(i) \neq \emptyset\}|}{|I|}$$

### 3.3 视觉连贯性

$$f_3(L) = -\sum_{(i,j) \in E_{adj}} d(L(i), L(j))$$

### 3.4 综合目标

$$F(L) = w_1 f_1 + w_2 f_2 + w_3 f_3$$

## 4. 组合优化算法

### 4.1 装箱问题建模

通书编排可视为二维装箱问题（2D-BPP）：

- 版面：固定大小的容器
- 信息单元：待装箱的矩形物品
- 目标：最小化使用容器数或最大化填充率

### 4.2 贪心算法

**首次适应算法（FF）**：

```
算法FF:
1. 按优先级排序信息单元
2. for each unit i:
3.     将 i 放入第一个能容纳它的位置
4.     if 无合适位置: 开启新页面
```

**最佳适应算法（BF）**：

选择使剩余空间最小的位置。

### 4.3 遗传算法

编码：信息单元的放置序列和位置

适应度：$fitness = F(L)$

操作：
- 交叉：部分映射交叉（PMX）
- 变异：交换两个单元位置或改变位置

### 4.4 模拟退火

邻域操作：
- 移动：改变单元位置
- 交换：交换两个单元位置
- 旋转：改变单元方向

## 5. 整数线性规划建模

### 5.1 决策变量

$$x_{i,p} = \begin{cases} 1 & \text{if 单元 } i \text{ 放置在位置 } p \\ 0 & \text{otherwise} \end{cases}$$

### 5.2 约束条件

**唯一放置约束**：

$$\sum_p x_{i,p} = 1, \quad \forall i$$

**非重叠约束**：

$$\sum_{i: p \in L(i)} x_{i,p} \leq 1, \quad \forall p$$

### 5.3 目标函数

$$\max \sum_{i,p} v_{i,p} \cdot x_{i,p}$$

其中 $v_{i,p}$ 为单元 $i$ 在位置 $p$ 的价值。

## 6. 层次化编排策略

### 6.1 宏观布局

确定各信息区块的位置：

- 日期区块
- 宜忌区块
- 时辰区块
- 神煞区块

### 6.2 微观布局

在每个区块内安排具体信息：

- 宜忌列表排序
- 时辰表格排列
- 神煞图标布局

### 6.3 层次优化

分层优化减少搜索空间：

$$\min_{L_{macro}} \min_{L_{micro}} F(L_{macro}, L_{micro})$$

## 7. 多页面编排

### 7.1 页面分配

将信息单元分配到多个页面：

$$P: I \to \{1, 2, \ldots, N_{page}\}$$

### 7.2 页面平衡

各页面信息量均衡：

$$\min \max_p |\{i : P(i) = p\}| - \min_p |\{i : P(i) = p\}|$$

### 7.3 连续性约束

跨页信息保持连续：

$$\forall (i, j) \in E_{seq}: |P(i) - P(j)| \leq 1$$

## 8. 结论

组合优化理论为通书编排提供了系统的数学方法。装箱问题、整数规划、启发式算法等概念与通书编排的版面利用、信息完整、视觉连贯等建立了精确的对应关系。该模型可用于通书的自动化编排和版面优化。
