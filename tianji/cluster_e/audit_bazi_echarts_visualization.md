# 开源项目审计报告：八字命盘可视化系统（ECharts实现）

## 项目概览

**项目名称**：八字命盘ECharts可视化系统

**技术栈**：JavaScript/TypeScript、ECharts v5、HTML5、CSS3

**功能定位**：基于Apache ECharts可视化库构建的八字（四柱）命盘交互式展示系统，支持命盘图表、大运流年、五行分析等多维度可视化

**许可证类型**：Apache 2.0（ECharts核心库）、MIT（典型实现项目）

**社区活跃度**：ECharts是Apache基金会顶级项目，GitHub Stars超过60k，企业级应用广泛

## 软件架构分析

### 整体架构设计

八字命盘可视化系统采用分层架构：

**数据计算层**：负责八字核心算法实现，包括四柱排盘、十神计算、五行统计、大运推算、流年分析等

**数据转换层**：将计算结果转换为ECharts可消费的图表数据格式（Option配置对象）

**可视化渲染层**：基于ECharts的各类图表组件实现命盘可视化

**交互控制层**：提供用户输入、图表联动、数据钻取等交互功能

### 模块划分详解

**八字计算引擎模块**：

- **四柱排盘子模块**：年柱、月柱、日柱、时柱计算
- **十神计算子模块**：根据日主推算十神关系
- **五行统计子模块**：计算五行力量分布
- **大运推子模块**：基于月柱推算大运周期
- **流年分析子模块**：流年干支与命盘作用关系

**图表渲染模块**：

- **四柱柱图**：使用ECharts柱状图展示四柱干支
- **五行饼图**：使用ECharts饼图展示五行分布
- **十神雷达图**：使用ECharts雷达图展示十神力量
- **大运时间轴**：使用ECharts时间轴组件展示大运流转
- **流年热力图**：使用ECharts热力图展示流年吉凶

**用户界面模块**：

- **输入表单**：出生日期、时间、性别、出生地输入
- **命盘展示区**：四柱、藏干、纳音、神煞展示
- **分析结果区**：五行分析、十神分析、大运分析

### 设计模式应用

**适配器模式**：将八字计算结果适配为ECharts Option格式

**观察者模式**：ECharts的事件机制支持图表联动

## 核心算法实现分析

### 四柱排盘算法

四柱即年柱、月柱、日柱、时柱，每柱由一个天干和一个地支组成。

**年柱计算**：

年干公式：

$$
\text{年干索引} = (\text{年份} - 4) \mod 10
$$

年支公式：

$$
\text{年支索引} = (\text{年份} - 4) \mod 12
$$

**时间复杂度**：$O(1)$

**月柱计算**：

月支固定对应：正月寅、二月卯、三月辰...十二月丑

月干根据年干确定，遵循"五虎遁"口诀：

$$
\text{月干索引} = (\text{年干索引} \times 2 + \text{月支索引}) \mod 10
$$

**时间复杂度**：$O(1)$

**日柱计算**：

日柱计算最为复杂，需要基于基准日期进行推算。

常用算法（简化版）：

```
输入：公历日期 date
输出：日柱（日干、日支）

1. 选择基准日期（如1900-01-31 = 甲辰日）
2. 计算目标日期与基准日期的天数差 delta
3. 日干索引 = (基准日干索引 + delta) mod 10
4. 日支索引 = (基准日支索引 + delta) mod 12
```

**时间复杂度**：$O(1)$ —— 使用预计算表或公式直接计算

**空间复杂度**：$O(1)$

**时柱计算**：

时支固定对应：子(23-1)、丑(1-3)、寅(3-5)...亥(21-23)

时干根据日干确定，遵循"五鼠遁"口诀：

$$
\text{时干索引} = (\text{日干索引} \times 2 + \text{时支索引}) \mod 10
$$

**时间复杂度**：$O(1)$

### 十神计算算法

十神（比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印）根据日干与其他干支的五行生克关系确定。

**五行生克关系**：

- 生：木→火→土→金→水→木
- 克：木→土→水→火→金→木

**十神判定规则**：

```
输入：日干 S，目标干 T
输出：十神类型

1. 判断S与T的阴阳属性
2. 判断S与T的五行生克关系
3. 根据生克关系和阴阳属性确定十神：
   - 同我且同阴阳：比肩
   - 同我且异阴阳：劫财
   - 我生且同阴阳：食神
   - 我生且异阴阳：伤官
   - 我克且同阴阳：偏财
   - 我克且异阴阳：正财
   - 克我且同阴阳：七杀
   - 克我且异阴阳：正官
   - 生我且同阴阳：偏印
   - 生我且异阴阳：正印
```

**时间复杂度**：$O(1)$ —— 查表或条件判断

**空间复杂度**：$O(1)$ —— 十神映射表固定大小

### 五行统计算法

统计命盘中各五行（木、火、土、金、水）的数量和力量。

**计算方法**：

```
输入：四柱干支
输出：五行力量分布

1. 初始化五行计数器：木=0, 火=0, 土=0, 金=0, 水=0
2. 遍历四柱天干：
   - 根据天干五行属性累加
3. 遍历四柱地支：
   - 根据地支主气五行属性累加
   - 根据地支藏干五行属性按比例累加（主气60%、中气30%、余气10%）
4. 返回五行分布
```

**时间复杂度**：$O(n)$，$n=8$（四柱共8个字）

**空间复杂度**：$O(1)$

### 大运推算算法

大运是八字命理中预测人生运势的重要工具，以月柱为基准顺排或逆排。

**大运排列规则**：

- 阳年男命、阴年女命：顺排（月柱→下一柱→...）
- 阴年男命、阳年女命：逆排（月柱→上一柱→...）

**起运年龄计算**：

```
输入：出生日期、性别、年干阴阳
输出：起运年龄

1. 计算出生日期到最近节气的天数差 D
2. 起运年龄 = D / 3（天/年）
3. 若顺排：从出生日期往后数 D 天找到起运日期
4. 若逆排：从出生日期往前数 D 天找到起运日期
```

**时间复杂度**：$O(1)$ —— 节气查表 + 简单计算

**空间复杂度**：$O(1)$

### 流年分析算法

流年是每年的干支，分析流年与命盘的作用关系。

**分析方法**：

```
输入：命盘四柱、流年干支
输出：流年分析结果

1. 判断流年干支与日主的关系（十神）
2. 判断流年干支与四柱各柱的作用
3. 分析流年对五行的影响
4. 综合判断流年吉凶
```

**时间复杂度**：$O(n)$，$n=4$（四柱）

**空间复杂度**：$O(1)$

## 天文历算库依赖分析

### 农历转换库选择

**lunar-javascript**：

- 功能：公历转农历、干支计算、节气计算
- 精度：满足八字排盘需求
- 体积：约50KB（minified）
- 许可：MIT

**true-solar-time**：

- 功能：真太阳时计算
- 精度：基于Jean Meeus天文算法
- 用途：处理出生地经度时差和均时差修正

**cnlunar-js**：

- 功能：cnlunar Python库的JavaScript移植
- 特点：支持八字排盘、节气、宜忌等

### 精度分析

**节气计算**：

- 简化算法误差：±2分钟
- 八字排盘以时辰为单位（2小时），该精度完全满足需求

**真太阳时**：

- 标准时与真太阳时最大差异：±17分钟
- 临界时辰（如23:00、1:00、3:00等）需特别注意

**日柱计算**：

- 基于基准日期的推算方法在2000年范围内精度可靠
- 极端日期（<1900或>2100）建议使用天文算法库

## 精度与准确性分析

### 四柱计算准确性

**年柱**：基于数学公式，100%准确

**月柱**：节气分界存在争议（节令时刻vs当日零时），建议提供选项

**日柱**：基于基准日期推算，1900-2100年范围内误差<1天

**时柱**：时辰分界存在争议（23:00vs 0:00），建议提供选项

### 十神计算准确性

十神判定基于五行生克规则，逻辑清晰，100%准确

### 大运推算准确性

**顺逆排**：基于年干阴阳和性别，规则明确，100%准确

**起运年龄**：节气天数差计算，精度取决于节气算法
