# 紫微斗数十四主星分布的概率模型

## 1. 模型概述

紫微斗数命盘由十四主星的分布决定基本格局。本模型建立十四主星在十二宫位分布的概率模型，分析其组合空间的统计特征、对称性质，以及特定格局的出现概率，为紫微斗数的量化研究提供数学基础。

## 2. 主星分布的基本约束

### 2.1 排布规则约束

十四主星的分布受到严格的排布规则约束：

**紫微星系约束**：紫微、天机、太阳、武曲、天同、廉贞六星必须按固定顺序连续排列在六个相邻宫位。

**天府星系约束**：天府、太阴、贪狼、巨门、天相、天梁、七杀、破军八星必须按固定顺序连续排列在八个相邻宫位。

**对称约束**：天府星的位置由紫微星的位置唯一确定：

$$idx_{天府} = (13 - idx_{紫微}) \mod 12$$

### 2.2 可行分布空间

设紫微星位置为 $p \in \{1, 2, ..., 12\}$，则：

**紫微星系位置**：

$$紫微_i = (p - i + 1) \mod 12, \quad i = 1, 2, ..., 6$$

**天府星系位置**：

$$天府_j = (13 - p - j + 1) \mod 12, \quad j = 1, 2, ..., 8$$

**可行分布数**：

由于紫微星有12个可能位置，主星分布的可行配置数为：

$$N_{可行} = 12$$

即只有12种不同的主星分布格局。

### 2.3 分布的群结构

主星分布空间同构于循环群 $Z_{12}$：

$$\phi: Z_{12} \to \mathcal{D}$$

其中 $\mathcal{D}$ 为主星分布集合。

群作用：旋转命盘12宫对应于紫微星位置的变化。

## 3. 主星分布的概率模型

### 3.1 均匀分布假设

假设出生时间均匀分布，紫微星位置的先验概率为：

$$P(p = k) = \frac{1}{12}, \quad k = 1, 2, ..., 12$$

### 3.2 紫微星位置的实际分布

紫微星位置由生日和局数决定：

$$p = f(d, b)$$

其中 $d \in \{1, 2, ..., 30\}$ 为生日，$b \in \{2, 3, 4, 5, 6\}$ 为局数。

**生日分布**：

农历生日在1-30天内近似均匀分布（考虑大小月）。

**局数分布**：

局数由命宫纳音决定，各局数的先验概率：

$$P(水二局) = P(木三局) = P(金四局) = P(土五局) = P(火六局) = \frac{1}{5}$$

**紫微星位置的条件概率**：

$$P(p = k) = \sum_{b} P(p = k \mid b) P(b)$$

### 3.3 紫微星位置的概率表

根据排布规则，不同局数下紫微星可能出现的位置：

**水二局**（$b=2$）：

紫微星位置与生日关系：

$$p = \left\lfloor \frac{d+1}{2} \right\rfloor \mod 12$$

生日1-24日时，紫微星在子宫到巳宫循环。

**各位置概率**：

由于生日均匀分布，各位置概率近似相等：

$$P(p = k \mid 水二局) \approx \frac{1}{12}$$

### 3.4 主星组合的概率

**特定主星在特定宫位的概率**：

设主星 $s$ 在宫位 $h$ 的概率为 $P(s \in h)$。

由于主星分布由紫微星位置唯一确定：

$$P(s \in h) = \sum_{p: s \in h \text{ 当紫微在 } p} P(p)$$

**示例**：紫微星在命宫的概率

紫微星在命宫当且仅当 $p = idx_{命宫}$。

$$P(紫微 \in 命宫) = P(p = idx_{命宫}) = \frac{1}{12}$$

## 4. 主星格局的概率分析

### 4.1 格局定义

**紫微在命宫格**：

$$格局_1: 紫微 \in 命宫$$

概率：$P(格局_1) = \frac{1}{12}$

**紫微天府朝垣格**：

$$格局_2: 紫微 \in 午宫 \land 天府 \in 子宫$$

概率：$P(格局_2) = P(p = 7) = \frac{1}{12}$

**君臣庆会格**：

$$格局_3: 紫微 \in 命宫 \land 天府 \in 财帛宫$$

需要紫微在命宫且命宫与财帛宫的相对位置满足条件。

### 4.2 格局概率计算

**双星同宫格**：

设主星 $s_1, s_2$ 同宫的概率：

$$P(s_1, s_2 \in 同一宫) = \sum_{p} I(s_1, s_2 \text{ 同宫} \mid p) \cdot P(p)$$

由于紫微星系内部和天府星系内部的主星不会同宫（按顺序排列），跨星系的主星可能同宫。

**紫微天府同宫**：

$$P(紫微, 天府 \in 同一宫) = 0$$

（由对称约束，紫微天府永不同宫）

**紫微七杀同宫**：

七杀在天府星系，可能与紫微同宫。

### 4.3 格局的联合概率

**多条件格局**：

设格局 $G$ 需要满足多个条件：

$$G = C_1 \land C_2 \land ... \land C_n$$

则：

$$P(G) = P(C_1) \cdot P(C_2 \mid C_1) \cdot ... \cdot P(C_n \mid C_1, ..., C_{n-1})$$

## 5. 主星分布的统计特征

### 5.1 主星在十二宫的分布

对每个主星 $s$，统计其在12宫的出现频率：

$$Freq(s, h) = \sum_{p=1}^{12} I(s \in h \mid 紫微在p)$$

**均匀性分析**：

若主星在各宫出现频率相等，则分布为均匀的。

计算方差：

$$Var(s) = \frac{1}{12} \sum_{h=1}^{12} (Freq(s, h) - \bar{Freq})^2$$

### 5.2 主星间的相关性

**同宫相关性**：

设主星 $s_i$ 和 $s_j$ 同宫的指示变量为 $X_{ij}$。

相关系数：

$$\rho_{ij} = \frac{Cov(X_i, X_j)}{\sqrt{Var(X_i) Var(X_j)}}$$

**对宫相关性**：

设主星 $s_i$ 和 $s_j$ 在对宫的指示变量为 $Y_{ij}$。

### 5.3 宫位的主星密度

**密度定义**：

宫位 $h$ 的主星密度为该宫的主星数量：

$$Density(h) = |\{s \mid s \in h\}|$$

**密度分布**：

由于紫微星系6星和天府星系8星分别占据6宫和8宫，且两星系有重叠：

$$Density(h) \in \{0, 1, 2\}$$

- 0星宫：无主星
- 1星宫：仅紫微星系或天府星系一星
- 2星宫：紫微星系和天府星系各一星

## 6. 主星分布的组合数学

### 6.1 排列组合分析

若无排布规则约束，14星分布在12宫的组合数为：

$$N_{无约束} = 12^{14}$$

考虑每宫最多2颗主星的约束：

$$N_{有约束} = C_{12}^{6} \cdot C_{12}^{8} \cdot 6! \cdot 8!$$

考虑排布规则的严格约束：

$$N_{实际} = 12$$

### 6.2 对称群作用

十二宫位的对称群为二面体群 $D_{12}$：

$$D_{12} = \langle r, s \mid r^{12} = s^2 = e, srs = r^{-1} \rangle$$

其中 $r$ 为旋转，$s$ 为反射。

主星分布在 $D_{12}$ 作用下的轨道：

$$Orb(d) = \{g \cdot d \mid g \in D_{12}\}$$

### 6.3 轨道-稳定子定理

由轨道-稳定子定理：

$$|Orb(d)| = \frac{|D_{12}|}{|Stab(d)|} = \frac{24}{|Stab(d)|}$$

对称性高的分布（如紫微在午宫）的稳定子较大，轨道较小。

## 7. 主星格局的熵分析

### 7.1 分布熵

主星分布的熵：

$$H(D) = -\sum_{d \in \mathcal{D}} P(d) \log P(d)$$

均匀分布时熵最大：

$$H_{max} = \log 12$$

### 7.2 条件熵

给定某些信息后的条件熵：

$$H(D \mid I) = -\sum_{d, i} P(d, i) \log P(d \mid i)$$

**示例**：已知局数后的条件熵

$$H(D \mid 局数) = \frac{1}{5} \sum_{b} H(D \mid 局数 = b)$$

### 7.3 互信息

不同变量间的互信息：

$$I(X; Y) = H(X) - H(X \mid Y)$$

**紫微位置与命宫位置的互信息**：

$$I(紫微位置; 命宫位置) = H(紫微位置) - H(紫微位置 \mid 命宫位置)$$

## 8. 主星分布的随机模拟

### 8.1 蒙特卡洛模拟

**算法**：

1. 随机生成生日 $d \sim U[1, 30]$
2. 随机生成局数 $b \sim U\{2, 3, 4, 5, 6\}$
3. 计算紫微星位置 $p = f(d, b)$
4. 排布主星
5. 记录统计信息
6. 重复N次

**统计量**：

- 各主星在各宫的出现频率
- 各格局的出现频率
- 主星同宫频率

### 8.2 大数定律

当模拟次数 $N \to \infty$：

$$\hat{P}(G) \to P(G)$$

$$\sqrt{N}(\hat{P}(G) - P(G)) \xrightarrow{d} N(0, \sigma^2)$$

### 8.3 置信区间

格局概率的95%置信区间：

$$\hat{P}(G) \pm 1.96 \sqrt{\frac{\hat{P}(G)(1-\hat{P}(G))}{N}}$$

## 9. 主星分布的假设检验

### 9.1 均匀性检验

检验主星在各宫的分布是否均匀：

**原假设** $H_0$：$P(s \in h) = \frac{1}{12}$ 对所有 $h$

**检验统计量**（卡方检验）：

$$\chi^2 = \sum_{h=1}^{12} \frac{(O_h - E_h)^2}{E_h}$$

其中 $O_h$ 为观测频数，$E_h = N/12$ 为期望频数。

### 9.2 独立性检验

检验两颗主星是否独立分布：

**原假设** $H_0$：$P(s_1, s_2 \in h) = P(s_1 \in h) P(s_2 \in h)$

### 9.3 格局显著性检验

检验某格局的出现频率是否显著高于随机水平：

$$Z = \frac{\hat{P}(G) - P_0(G)}{\sqrt{P_0(G)(1-P_0(G))/N}}$$

## 10. 结论

紫微斗数十四主星分布的概率模型建立了主星格局的统计框架：

- **可行空间**：受排布规则约束，主星分布仅有12种可行配置
- **群结构**：主星分布空间同构于 $Z_{12}$，具有循环群结构
- **概率模型**：基于生日和局数的均匀分布假设，各紫微位置概率相等
- **格局概率**：特定格局的概率可通过条件概率公式计算
- **统计特征**：主星在各宫的分布频率、相关性可通过统计方法分析
- **熵分析**：分布熵、条件熵、互信息提供了信息论视角
- **随机模拟**：蒙特卡洛方法可用于验证理论概率
- **假设检验**：统计检验可用于验证分布假设和格局显著性

该模型为紫微斗数的量化研究、格局分析和科学研究提供了数学基础。
