# 农历与公历转换的高精度算法

## 摘要

农历与公历的转换是中国传统历法计算的基础问题。本文基于天文算法和历法规则，建立农历与公历转换的数学模型，提出高精度转换算法，并分析转换误差来源。该算法可精确到秒级，满足现代天文和历法研究的需求。

## 一、历法基础

### 1.1 公历（格里高利历）

**基本参数**

- 平年：365天
- 闰年：366天
- 闰年规则：能被4整除但不能被100整除，或能被400整除

**儒略日数**

儒略日数（JD）是连续计数的天数：

$$\text{JD} = \text{从公元前4713年1月1日中午起算的天数}$$

公历日期转儒略日数：

$$\text{JD} = 1721425.5 + 365(Y-1) + \lfloor\frac{Y-1}{4}\rfloor - \lfloor\frac{Y-1}{100}\rfloor + \lfloor\frac{Y-1}{400}\rfloor + D$$

其中：
- $Y$ 是年份
- $D$ 是该年的第几天

### 1.2 农历

**基本参数**

- 朔望月：29.530588天（平均）
- 回归年：365.2422天（平均）
- 闰月规则：无中气之月置闰

**农历月份**

农历月份由朔日确定：

$$\text{农历月} = \text{从朔日到下一个朔日之间的天数}$$

大月：30天
小月：29天

**二十四节气**

二十四节气将回归年24等分：

$$\Delta T_{\text{节气}} = \frac{365.2422}{24} \approx 15.22 \text{天}$$

中气：冬至、大寒、雨水、春分、谷雨、小满、夏至、大暑、处暑、秋分、霜降、小雪
节气：小寒、立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪

### 1.3 干支纪年

**天干**

甲、乙、丙、丁、戊、己、庚、辛、壬、癸（10个）

**地支**

子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥（12个）

**干支组合**

$$\text{干支序号} = ((\text{年} - 4) \mod 60)$$

天干序号：$(\text{年} - 4) \mod 10$
地支序号：$(\text{年} - 4) \mod 12$

## 二、农历计算的天文基础

### 2.1 朔望月计算

**朔的定义**

朔是日月黄经相等的时刻：

$$\lambda_{\text{月}} = \lambda_{\text{日}}$$

**朔望月长度**

朔望月长度变化：

$$L_{\text{朔望}} = 29.530588 + 0.0000002 \cdot T - 0.00000002 \cdot T^2$$

其中 $T$ 是从J2000.0起算的儒略世纪数：

$$T = \frac{\text{JD} - 2451545.0}{36525}$$

### 2.2 太阳黄经计算

**太阳平黄经**

$$L_0 = 280.46646 + 36000.76983 \cdot T + 0.0003032 \cdot T^2$$

**太阳真黄经**

$$\lambda_{\text{日}} = L_0 + \Delta\lambda$$

其中 $\Delta\lambda$ 是中心差修正：

$$\Delta\lambda = \sum_{i} C_i \sin(E_i)$$

### 2.3 月球黄经计算

**月球平黄经**

$$L_{\text{月}} = 218.3164477 + 481267.88123421 \cdot T - 0.0015786 \cdot T^2$$

**月球真黄经**

$$\lambda_{\text{月}} = L_{\text{月}} + \Delta\lambda_{\text{月}}$$

其中 $\Delta\lambda_{\text{月}}$ 包含：
- 中心差
- 出差
- 周年差
- 月角差
- 二均差

### 2.4 二十四节气计算

**节气黄经**

二十四节气的太阳黄经：

$$\lambda_k = k \times 15°, \quad k = 0, 1, 2, \ldots, 23$$

其中 $k=0$ 对应冬至。

**节气时刻计算**

求解方程：

$$\lambda_{\text{日}}(t) = \lambda_k$$

使用牛顿迭代法求解。

## 三、公历转农历算法

### 3.1 算法框架

**算法3.1（公历转农历）**

输入：公历年 $Y$，月 $M$，日 $D$
输出：农历年 $y$，月 $m$，日 $d$，是否闰月

1. 计算儒略日数 $\text{JD}$
2. 确定农历年首（冬至后的第二个朔日）
3. 计算该年所有朔日
4. 确定农历月份
5. 确定是否闰月
6. 计算农历日
7. 计算农历干支

### 3.2 核心计算步骤

**步骤1：计算儒略日数**

$$\text{JD} = 367Y - \lfloor\frac{7(Y + \lfloor\frac{M+9}{12}\rfloor)}{4}\rfloor + \lfloor\frac{275M}{9}\rfloor + D + 1721013.5$$

**步骤2：计算冬至**

冬至时刻：

$$\text{JD}_{\text{冬至}} = \text{FindRoot}(\lambda_{\text{日}}(t) = 270°)$$

**步骤3：计算朔日**

朔日序列：

$$\text{JD}_{\text{朔},i} = \text{FindRoot}(\lambda_{\text{月}}(t) = \lambda_{\text{日}}(t))$$

**步骤4：确定农历月份**

找到包含目标日期的朔望月：

$$\text{JD}_{\text{朔},i} \leq \text{JD} < \text{JD}_{\text{朔},i+1}$$

**步骤5：确定闰月**

检查该月是否包含中气：

$$\text{闰月} = \mathbb{I}(\text{该月无中气})$$

### 3.3 高精度实现

**牛顿迭代法求朔**

迭代公式：

$$t_{n+1} = t_n - \frac{f(t_n)}{f'(t_n)}$$

其中：

$$f(t) = \lambda_{\text{月}}(t) - \lambda_{\text{日}}(t)$$

$$f'(t) = \frac{d\lambda_{\text{月}}}{dt} - \frac{d\lambda_{\text{日}}}{dt}$$

**收敛条件**

$$|t_{n+1} - t_n| < \epsilon$$

其中 $\epsilon = 10^{-8}$ 天（约0.001秒）。

### 3.4 算法复杂度

**时间复杂度**

- 计算儒略日数：$O(1)$
- 计算朔日：$O(k)$，$k$ 是迭代次数（通常5-10次）
- 确定月份：$O(n)$，$n$ 是该年的月数（12或13）

总时间复杂度：$O(n)$

**空间复杂度**

$O(n)$，用于存储朔日序列

## 四、农历转公历算法

### 4.1 算法框架

**算法4.1（农历转公历）**

输入：农历年 $y$，月 $m$，日 $d$，是否闰月
输出：公历年 $Y$，月 $M$，日 $D$

1. 确定农历年首
2. 计算该年所有朔日
3. 确定目标朔日
4. 计算公历日期

### 4.2 核心计算步骤

**步骤1：确定农历年首**

农历年首是冬至后的第二个朔日：

$$\text{JD}_{\text{年首}} = \text{JD}_{\text{朔},2}(\text{冬至})$$

**步骤2：计算朔日序列**

从年首开始，依次计算朔日：

$$\text{JD}_{\text{朔},i+1} = \text{JD}_{\text{朔},i} + L_{\text{朔望}}$$

**步骤3：确定目标朔日**

考虑闰月，确定目标月份的朔日：

$$\text{JD}_{\text{目标}} = \text{JD}_{\text{朔},m'}$$

其中 $m'$ 考虑闰月后的实际月序。

**步骤4：计算公历日期**

$$\text{JD} = \text{JD}_{\text{目标}} + d - 1$$

将儒略日数转换为公历日期。

### 4.3 闰月处理

**闰月判定**

根据农历规则，无中气之月置闰：

$$\text{闰月序号} = \text{Find}(\text{该月无中气})$$

**闰月映射**

输入月份 $m$ 和闰月标志：

- 如果 $m <$ 闰月序号：实际月序 = $m$
- 如果 $m =$ 闰月序号且为闰月：实际月序 = 闰月
- 如果 $m \geq$ 闰月序号：实际月序 = $m + 1$

## 五、精度分析与误差控制

### 5.1 误差来源

**天文常数误差**

- 朔望月长度：误差约 $10^{-7}$ 天
- 太阳黄经：误差约 $0.001°$
- 月球黄经：误差约 $0.01°$

**计算误差**

- 迭代收敛误差：$10^{-8}$ 天
- 浮点运算误差：$10^{-15}$ 天

**历法规则误差**

- 古代历法与现代天文的差异
- 历法改革的影响

### 5.2 精度评估

**朔日计算精度**

理论精度：

$$\sigma_{\text{朔日}} \approx 0.001 \text{ 秒}$$

**节气计算精度**

理论精度：

$$\sigma_{\text{节气}} \approx 0.01 \text{ 秒}$$

**日期转换精度**

实际精度：

$$\sigma_{\text{日期}} \approx 1 \text{ 秒}$$

### 5.3 误差控制方法

**方法1：使用高精度天文常数**

采用IAU推荐的天文常数：

- 天文单位：$1 \text{ AU} = 149597870700 \text{ m}$
- 光速：$c = 299792458 \text{ m/s}$

**方法2：增加迭代次数**

提高牛顿迭代的收敛精度：

$$\epsilon = 10^{-12} \text{ 天}$$

**方法3：使用高精度浮点数**

使用双精度浮点数（64位）或更高精度。

## 六、算法优化

### 6.1 查表法优化

**预计算表**

预计算1900-2100年的朔日和节气：

$$\text{Table}[\text{年}] = \{\text{JD}_{\text{朔},1}, \text{JD}_{\text{朔},2}, \ldots, \text{JD}_{\text{节气},1}, \ldots\}$$

**查表转换**

转换时直接查表，时间复杂度降为 $O(1)$。

### 6.2 近似公式优化

**朔日近似公式**

$$\text{JD}_{\text{朔}} \approx \text{JD}_0 + k \cdot 29.530588$$

其中 $\text{JD}_0$ 是基准朔日。

**节气近似公式**

$$\text{JD}_{\text{节气}} \approx \text{JD}_{\text{冬至}} + k \cdot 15.22$$

### 6.3 并行计算优化

**批量转换**

对于大量日期转换，使用并行计算：

```python
from multiprocessing import Pool

def parallel_convert(dates):
    with Pool(processes=4) as pool:
        results = pool.map(convert, dates)
    return results
```
