# 顾炎武学术图谱考据

## 一、人物生平概览

**生卒年份**：公元1613年-1682年，享年69岁

**籍贯考辨**：江苏昆山（今江苏昆山市）人，初名绛，字宁人，号亭林，自署蒋山佣。昆山地处江南腹地，是明代经济文化最发达的地区之一。明代属南直隶苏州府。

**时代背景**：顾炎武生活于明清鼎革之际，亲历明朝灭亡、清军入关等重大历史事件。其学术思想深受时代影响，形成"经世致用"的学术取向。

**抗清经历**：顾炎武青年时期即投身抗清斗争。清兵南下时，参加昆山抗清起义。起义失败后，其嗣母王氏殉国，临终遗言"无为异国臣子"，对顾炎武影响深远。

**游历考察**：顾炎武后半生游历北方，足迹遍及山东、河北、山西、陕西等地，考察地理、风俗、民生，收集资料，为其学术研究奠定基础。

**学术特点**：顾炎武治学注重实地考察与文献考证相结合，强调"经世致用"，反对空谈性理。

## 二、学术突破与理论创新

### 2.1 经世致用思想

顾炎武提出"经世致用"的学术主张，对后世产生深远影响：

**"经世致用"的内涵**：

- 学术研究应服务于社会现实
- 学问要有益于治国平天下
- 反对空谈性理，强调实学

**"天下兴亡，匹夫有责"**：

- 提出这一著名命题
- 强调知识分子的社会责任
- 体现其强烈的家国情怀

### 2.2 音韵学研究

顾炎武在音韵学领域有开创性贡献：

**《音学五书》**：

- 《音论》：音韵学理论
- 《诗本音》：《诗经》用韵研究
- 《易音》：《周易》用韵研究
- 《唐韵正》：唐代音韵研究
- 《古音表》：古音系统整理

**学术价值**：

- 开创清代古音学研究
- 为后世音韵学奠定基础
- 对《周易》音韵的研究有独特价值

### 2.3 地理学研究

顾炎武在地理学领域的代表作是《天下郡国利病书》和《肇域志》：

**《天下郡国利病书》**：

- 收录各地地理、经济、军事资料
- 注重实用，服务于经世致用
- 为地方志研究的重要参考

**《肇域志》**：

- 地理学专著
- 系统记载各地地理情况
- 体现其实地考察成果

### 2.4 易学研究

顾炎武对《周易》有深入研究，主要体现在《易音》中：

**《易音》的特点**：

- 从音韵角度研究《周易》
- 考证《周易》的用韵规律
- 为易学研究提供新视角

**易学观点**：

- 反对将《周易》用于卜筮
- 主张从义理角度理解《周易》
- 注重《周易》的经世价值

### 2.5 考据学方法

顾炎武开创了清代考据学的方法：

**"实事求是"**：

- 强调证据的重要性
- 反对主观臆断
- 注重文献与实物相结合

**"博学于文""行己有耻"**：

- 提出为学之道
- 强调学问与德行的统一

### 2.6 与同时代学者的比较

与王夫之的比较：

- 顾炎武注重经世致用，王夫之注重哲学建构
- 顾炎武偏重考据，王夫之偏重义理
- 二人都反对空谈性理

与黄宗羲的比较：

- 顾炎武偏重经学与史学，黄宗羲偏重史学与政治思想
- 顾炎武注重实地考察，黄宗羲注重文献研究
- 二人都强调经世致用
