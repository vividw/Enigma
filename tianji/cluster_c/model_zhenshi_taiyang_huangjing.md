# 真实太阳黄经与平太阳差异模型

## 一、问题定义

中国古代历法以太阳视运动为基础，节气计算依赖于太阳黄经。由于地球轨道为椭圆，真实太阳黄经与平太阳黄经存在差异（均时差）。本节建立这一差异的数学模型，为高精度节气计算提供理论基础。

## 二、天文基础

### 2.1 太阳黄经的定义

太阳黄经 $\lambda$ 是太阳在黄道坐标系中的角位置，以春分点为0度起点，向东计量。

### 2.2 平太阳黄经

假设地球以匀速做圆周运动，平太阳黄经为：

$$\bar{\lambda} = L_0 + n \cdot t$$

其中：
- $L_0$ 为历元平黄经
- $n = 360° / 365.25 \approx 0.9856°/\text{天}$ 为平运动速率
- $t$ 为距历元的时间

### 2.3 真实太阳黄经

真实太阳黄经由开普勒方程确定：

$$M = E - e \sin E$$

$$\lambda = \nu + \varpi = 2 \arctan\left(\sqrt{\frac{1+e}{1-e}} \tan\frac{E}{2}\right) + \varpi$$

其中：
- $M$ 为平近点角
- $E$ 为偏近点角
- $e$ 为轨道偏心率
- $\nu$ 为真近点角
- $\varpi$ 为近日点黄经

## 三、均时差的数学模型

### 3.1 均时差的定义

均时差（Equation of Time）为平太阳时与真太阳时之差：

$$\text{EoT} = \bar{\lambda} - \lambda$$

### 3.2 均时差的组成

均时差由两部分组成：

**轨道偏心效应**：

$$\Delta_1 = -2e \sin M + \frac{5}{4}e^2 \sin 2M + O(e^3)$$

**黄赤交角效应**：

$$\Delta_2 = -\tan^2\frac{\varepsilon}{2} \sin 2\lambda + \frac{1}{2}\tan^4\frac{\varepsilon}{2} \sin 4\lambda + O(\tan^6\frac{\varepsilon}{2})$$

其中 $\varepsilon$ 为黄赤交角。

### 3.3 均时差的完整公式

$$\text{EoT} = \Delta_1 + \Delta_2$$

展开到一阶：

$$\text{EoT} \approx -2e \sin M - \tan^2\frac{\varepsilon}{2} \sin 2\lambda$$

### 3.4 数值参数

- 偏心率：$e \approx 0.0167$
- 黄赤交角：$\varepsilon \approx 23.44°$

## 四、均时差的周期分析

### 4.1 年度周期

均时差呈现年度周期变化，主要由轨道偏心引起。

### 4.2 半年周期

黄赤交角效应产生半年周期分量。

### 4.3 完整周期

均时差的完整周期为一年，但非正弦波形。

### 4.4 极值分析

均时差的极值约为 $\pm 16$ 分钟。

- 最大值：约 +16.4 分钟（11月初）
- 最小值：约 -14.2 分钟（2月中旬）

## 五、高精度计算模型

### 5.1 VSOP87理论

VSOP87（Variations Seculaires des Orbites Planetaires）是行星轨道的高精度理论。

太阳黄经的VSOP87表达式：

$$\lambda = \sum_{i} A_i \cos(B_i + C_i T) + S_i T^i$$

其中 $T$ 为儒略世纪数，$A_i, B_i, C_i$ 为理论系数。

### 5.2 简化高精度公式

对于1900-2100年，可使用以下简化公式：

$$\lambda = 280.46061837 + 360.007700536 T + 0.0003025 T^2$$

$$+ 1.25 \times 10^{-5} T^3 + \delta\lambda$$

其中摄动项：

$$\delta\lambda = 1.914666 \sin g + 0.019994 \sin 2g + 0.000293 \sin 3g$$

$$g = 357.52911 + 35999.05029 T - 1.537 \times 10^{-4} T^2$$

### 5.3 均时差的计算

$$\text{EoT} = 4(\bar{\lambda} - \lambda) \text{（转换为分钟）}$$

## 六、节气时刻的修正

### 6.1 平节气时刻

假设匀速运动，节气间隔为：

$$\Delta t_{\text{mean}} = \frac{365.25}{24} \approx 15.22 \text{ 天}$$

### 6.2 真节气时刻

真节气时刻需修正均时差：

$$t_{\text{true}} = t_{\text{mean}} + \frac{\text{EoT}}{24 \times 60} \text{ 天}$$

### 6.3 节气修正量

各节气的修正量不同，最大可达约1天。

## 七、误差分析

### 7.1 简化公式的误差

简化公式（仅考虑一阶偏心效应）的误差约为 $\pm 0.5°$。

### 7.2 高精度公式的误差

VSOP87理论的误差约为 $\pm 0.001°$。

### 7.3 节气时刻的误差

节气时刻计算误差：

- 简化公式：约 $\pm 12$ 小时
- 高精度公式：约 $\pm 1$ 分钟

## 八、算法实现

### 8.1 均时差计算

```
算法：CalculateEoT
输入：儒略日数 JD
输出：均时差（分钟）

1. 计算儒略世纪数 T = (JD - 2451545.0) / 36525
2. 计算平近点角 g = 357.52911 + 35999.05029*T
3. 计算平黄经 L0 = 280.46061837 + 360.007700536*T
4. 计算摄动项 dL = 1.914666*sin(g) + 0.019994*sin(2*g)
5. 计算真黄经 lambda = L0 + dL
6. 计算均时差 EoT = 4*(L0 - lambda)  // 转换为分钟
7. 返回 EoT
```

### 8.2 节气时刻计算

```
算法：CalculateSolarTerm
输入：年份 Y，节气序号 s（0-23）
输出：节气时刻（儒略日数）

1. 计算目标黄经 targetLon = s * 15
2. 估算初始时刻 JD0 = JD(Y, 1, 1) + s * 15.22
3. 迭代求解：
      对于 iter 从 1 到 10：
         lambda = CalculateSunLongitude(JD0)
         EoT = CalculateEoT(JD0)
         delta = (lambda - targetLon) / 0.9856
         JD0 = JD0 - delta
4. 返回 JD0
```
