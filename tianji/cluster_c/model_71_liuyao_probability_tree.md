# 六爻变卦的概率树模型

## 1. 六爻卦象的数学表示

六爻卦由六个爻位组成，每爻为阳（—）或阴（- -），可表示为6维二元向量。

### 1.1 卦象的向量表示

六爻卦：$\vec{G} = (g_1, g_2, g_3, g_4, g_5, g_6)$

其中 $g_i \in \{0, 1\}$，$0$ 表示阴爻，$1$ 表示阳爻。

### 1.2 卦象空间

所有可能的卦象：$\mathcal{G} = \{0, 1\}^6$，$|\mathcal{G}| = 64$

### 1.3 变爻的表示

变爻指示向量：$\vec{V} = (v_1, v_2, v_3, v_4, v_5, v_6)$

其中 $v_i = 1$ 表示第 $i$ 爻变，$v_i = 0$ 表示不变。

## 2. 变卦的概率模型

### 2.1 单爻变概率

每爻变概率：$p_i = P(v_i = 1)$

传统铜钱占卜：$p_i = \frac{1}{4}$（三枚铜钱，每枚正反面概率各 $\frac{1}{2}$）

### 2.2 变爻数的分布

变爻数 $K = \sum_{i=1}^{6} v_i$ 服从二项分布：

$$P(K = k) = \binom{6}{k} p^k (1-p)^{6-k}$$

### 2.3 变卦概率

给定本卦 $\vec{G}$，变卦 $\vec{G}'$ 的概率：

$$P(\vec{G}' | \vec{G}) = \prod_{i=1}^{6} P(g_i' | g_i)$$

其中：

$$P(g_i' | g_i) = \begin{cases} 1-p & g_i' = g_i \\ p & g_i' \neq g_i \end{cases}$$

## 3. 概率树模型

### 3.1 变卦树

以本卦为根，变爻为边，构建概率树：

- 深度：0到6（变爻数）
- 节点：卦象
- 边：单爻变，权重 $p$ 或 $1-p$

### 3.2 路径概率

从根到叶的路径概率：

$$P(path) = p^k (1-p)^{6-k}$$

其中 $k$ 为路径上的变爻数。

### 3.3 叶节点概率

变卦 $\vec{G}'$ 的总概率：

$$P(\vec{G}') = \sum_{paths \to \vec{G}'} P(path)$$

## 4. 六爻的马尔可夫模型

### 4.1 爻位转移

相邻爻位的关系可建模为马尔可夫链：

$$P(g_{i+1} | g_i, g_{i-1}, \ldots) = P(g_{i+1} | g_i)$$

### 4.2 转移矩阵

$$P = \begin{pmatrix} P(0|0) & P(1|0) \\ P(0|1) & P(1|1) \end{pmatrix}$$

### 4.3 稳态分布

$$\pi = \pi P$$

对于均匀分布：$\pi = (0.5, 0.5)$

## 5. 六爻的信息论分析

### 5.1 卦象熵

单爻熵：$H(g_i) = -p\log p - (1-p)\log(1-p)$

六爻总熵（独立假设）：$H(\vec{G}) = 6H(g_i)$

### 5.2 互信息

相邻爻的互信息：

$$I(g_i; g_{i+1}) = H(g_i) + H(g_{i+1}) - H(g_i, g_{i+1})$$

### 5.3 变卦信息量

变卦 $\vec{G}'$ 的信息量：

$$I(\vec{G}') = -\log P(\vec{G}')$$

## 6. 六爻的统计推断

### 6.1 参数估计

从历史数据估计变爻概率：

$$\hat{p} = \frac{\sum \text{变爻数}}{\sum \text{总爻数}}$$

### 6.2 假设检验

检验变爻概率是否符合理论值：

$$H_0: p = 0.25$$

$$Z = \frac{\hat{p} - 0.25}{\sqrt{0.25 \times 0.75 / n}}$$

### 6.3 置信区间

$$CI = \left[\hat{p} - z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}, \hat{p} + z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\right]$$

## 7. 六爻的随机模拟

### 7.1 蒙特卡洛模拟

模拟大量六爻占卜：

1. 随机生成本卦
2. 按概率生成变爻
3. 计算变卦
4. 统计分析

### 7.2 变卦分布

模拟得到变卦频率分布，与理论比较。

### 7.3 稀有变卦

计算特定变卦的稀有度：

$$Rarity = -\log_2 P(\vec{G}')$$

## 8. 结论

概率论和信息论为六爻变卦分析提供了严格的数学框架。概率树、马尔可夫链、信息熵、统计推断等概念与六爻占卜中的变卦规律、信息量、预测效果等建立了精确的对应关系。该模型可用于六爻占卜的定量分析和科学验证。
