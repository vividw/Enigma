# 天机知识库目录导航

这个目录收录了天机（TianJi）知识图谱当前同步到仓库的主文件与分集群内容，便于在 GitHub 中直接浏览。

## 主入口
- [`index.md`](./index.md)：总索引与六大集群导航。
- [`FINAL_REPORT.md`](./FINAL_REPORT.md)：最终成果报告。
- [`statistics_report.md`](./statistics_report.md)：统计明细。
- [`term_glossary.md`](./term_glossary.md)：术语表。
- [`term_index.md`](./term_index.md)：术语索引。
- [`cross_references.md`](./cross_references.md)：跨主题引用关系。
- [`orphan_nodes.md`](./orphan_nodes.md)：待补链节点记录。

## 目录结构
```text
tianji/
├── cluster_a/          宗师图谱与人物考据
├── cluster_b/          古典文献拆解与版本考证
├── cluster_c/          数理模型与算法推演
├── cluster_d/          现代交叉学科综述
├── cluster_e/          开源项目源码审计
├── cluster_a_index.md
├── cluster_b_index.md
├── cluster_c_index.md
├── cluster_d_index.md
├── cluster_e_index.md
└── 其他索引与统计文件
```
