## 一、二十四山向的概念体系

## 二、坐度分金的数学模型

### 2.1 分金的概念

分金是将每山15度进一步细分为5份，每份3度。

**定义（分金集合）**：分金集合 $\mathcal{F} = \{1, 2, 3, 4, 5\}$，对应：
- 1分金：0°-3°
- 2分金：3°-6°
- 3分金：6°-9°
- 4分金：9°-12°
- 5分金：12°-15°

### 2.2 坐度分金的计算

**定义（坐度分金映射）**：给定角度 $lpha \in [0, 360)$，计算其山向和分金：

**算法（角度转山向分金）**：

输入：角度 $lpha \in [0, 360)$

1. 计算山向索引：$k = \lfloor lpha / 15 floor \mod 24$
2. 确定山向：查二十四山表得 $s$
3. 计算分金：$f = \lfloor (lpha \mod 15) / 3 floor + 1$

输出：山向 $s$，分金 $f$

### 2.3 分金的吉凶判断

**定义（分金吉凶）**：分金有"正针"、"兼针"、"差错"之分。

**定理（分金吉凶规则）**：
- 1、3、5分金为正针（吉）
- 2、4分金为差错（凶）

## 三、一百二十分金的数学模型

### 3.1 一百二十分金的概念

一百二十分金是将每山15度细分为120份，每份0.125度（7.5分）。

**定义（一百二十分金）**：一百二十分金将360度分为120份，每份对应一个干支组合。

### 3.2 一百二十分金的计算

**算法（角度转一百二十分金）**：

输入：角度 $lpha \in [0, 360)$

1. 计算分金索引：$i = \lfloor lpha / 3 floor \mod 120$
2. 查表得干支组合

输出：干支组合

### 3.3 一百二十分金的吉凶

**定义（一百二十分金吉凶）**：一百二十分金分为"旺相"、"孤虚"、"空亡"三类。

**定理（一百二十分金吉凶判定）**：根据干支纳音与山向五行的生克关系判定。

## 四、坐向分金的综合计算模型

### 4.1 坐山与向首的关系

**定义（坐向关系）**：坐山与向首相差180度，即：

$$	heta_{	ext{向}} = (	heta_{	ext{坐}} + 180) \mod 360$$

**定理（坐向山向关系）**：若坐山为 $s$，则向首为与 $s$ 相对的山。

### 4.2 坐向分金的综合计算

**算法（坐向分金计算）**：

输入：坐山角度 $	heta_{	ext{坐}}$

1. 计算坐山山向分金：$(s_{	ext{坐}}, f_{	ext{坐}})$
2. 计算向首角度：$	heta_{	ext{向}} = (	heta_{	ext{坐}} + 180) \mod 360$
3. 计算向首山向分金：$(s_{	ext{向}}, f_{	ext{向}})$

输出：坐山 $(s_{	ext{坐}}, f_{	ext{坐}})$，向首 $(s_{	ext{向}}, f_{	ext{向}})$

```python
SHAN_NAMES = ["壬", "子", "癸", "丑", "艮", "寅", "甲", "卯", "乙", 
              "辰", "巽", "巳", "丙", "午", "丁", "未", "坤", "申",
              "庚", "酉", "辛", "戌", "乾", "亥"]

def angle_to_shanfen(angle):
    """角度转山向分金"""
    # 规范化角度到[0, 360)
    angle = angle % 360

    # 计算山向索引
    shan_idx = int(angle // 15) % 24
    shan = SHAN_NAMES[shan_idx]

    # 计算分金
    offset = angle % 15
    fenjin = int(offset // 3) + 1

    return shan, fenjin
```

## 七、分金模型的扩展应用

### 7.1 在阳宅立向中的应用

**定理（立向原则）**：阳宅立向应选择吉利的分金，避开差错空亡。

### 7.2 在阴宅造葬中的应用

**定理（造葬原则）**：阴宅造葬应选择旺相分金，以利后人。

### 7.3 分金的统计特性

**定理（分金均匀分布）**：在360度范围内，每山、每分金出现的概率相等。
