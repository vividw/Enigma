## 一、三元九运的概念体系

### 1.1 三元的数学定义

三元是玄空风水中最大的时间周期划分，将时间划分为上元、中元、下元三个等长区间。

**定义（三元周期）**：设一元长度为 $T_1 = 60$ 年，则三元总周期为：

$$T_{	ext{三元}} = 3 	imes T_1 = 180 	ext{ 年}$$

**定义（三元映射）**：三元映射 $	au: \mathbb{N} 	o \{	ext{上元}, 	ext{中元}, 	ext{下元}\}$ 定义为：

$$	au(y) = egin{cases}
	ext{上元} & (y - y_0) \mod 180 \in [0, 60) \
	ext{中元} & (y - y_0) \mod 180 \in [60, 120) \
	ext{下元} & (y - y_0) \mod 180 \in [120, 180)
\end{cases}$$

其中 $y_0$ 为基准年份（通常取1864年为上元开始）。

### 1.2 九运的数学定义

九运将三元进一步细分为九个20年的运期。

**定义（九运周期）**：设一运长度为 $T_2 = 20$ 年，则九运总周期为：

$$T_{	ext{九运}} = 9 	imes T_2 = 180 	ext{ 年} = T_{	ext{三元}}$$

**定义（九运映射）**：九运映射 $\eta: \mathbb{N} 	o \{1, 2, \ldots, 9\}$ 定义为：

$$\eta(y) = \left\lfloor rac{(y - y_0) \mod 180}{20} ightfloor + 1$$

### 1.3 三元与九运的联合映射

**定义（三元九运联合映射）**：联合映射 $\Psi: \mathbb{N} 	o \{	ext{上}, 	ext{中}, 	ext{下}\} 	imes \{1, 2, \ldots, 9\}$ 为：

$$\Psi(y) = (	au(y), \eta(y))$$

**定理（映射一致性）**：上元对应1-3运，中元对应4-6运，下元对应7-9运。

*证明*：上元为第0-60年，对应 $\lfloor 0/20 floor + 1 = 1$ 到 $\lfloor 59/20 floor + 1 = 3$ 运。同理可证中元、下元。$\square$

## 二、三元九运的周期结构

### 2.1 周期的群论描述

**定义（周期群）**：三元九运周期结构可描述为循环群 $C_{180}$ 的商群结构。

**定理（周期分解）**：$C_{180} \cong C_3 	imes C_{60} \cong C_9 	imes C_{20}$

*证明*：$180 = 3 	imes 60 = 9 	imes 20$，且 $\gcd(3, 60) = 3 
eq 1$，故严格同构需考虑直积结构。$\square$

### 2.2 运星入中宫的数学模型

**定义（运星映射）**：第 $n$ 运的运星入中宫，运星映射 $\sigma: \{1, \ldots, 9\} 	o \{1, \ldots, 9\}$ 为：

$$\sigma(n) = n$$

即第1运1星入中，第2运2星入中，依此类推。

**定理（运星周期性）**：运星以9运为周期循环，即 $\sigma(n + 9) = \sigma(n)$。

### 2.3 三元九运与洛书九宫的关系

## 三、三元九运的时间计算模型

### 3.1 年份到运数的转换

**算法（年份转运数）**：

输入：公历年份 $y$

1. 计算相对于基准年的偏移：$\Delta y = y - 1864$
2. 计算三元周期内的位置：$p = \Delta y \mod 180$
3. 计算运数：$n = \lfloor p / 20 floor + 1$

输出：运数 $n \in \{1, \ldots, 9\}$

### 3.2 运数到年份区间的转换

**算法（运数转年份区间）**：

输入：运数 $n \in \{1, \ldots, 9\}$，基准年 $y_0 = 1864$

1. 计算起始偏移：$s = (n - 1) 	imes 20$
2. 计算起始年份：$y_{	ext{start}} = y_0 + s$
3. 计算结束年份：$y_{	ext{end}} = y_{	ext{start}} + 19$

输出：年份区间 $[y_{	ext{start}}, y_{	ext{end}}]$

### 3.3 当前运期计算实例

**实例**：计算2024年所属运期

1. $\Delta y = 2024 - 1864 = 160$
2. $p = 160 \mod 180 = 160$
3. $n = \lfloor 160 / 20 floor + 1 = 9$

**结果**：2024年属于下元九运（2024-2043年）。

## 四、三元九运与宅命的数学关系

### 4.1 宅命星计算

**定义（宅命星）**：宅命星由建筑坐向和建造运期共同决定。

**定理（宅命星公式）**：设建造运期为 $n$，坐山星为 $s$，向首星为 $f$，则宅命星 $h$ 为：

$$h = (10 - n) \mod 9$$

若结果为0则取9。

### 4.2 运盘飞星计算

**定义（运盘）**：运盘是某运期内九宫飞星的静态分布。

**定理（运盘飞星公式）**：第 $n$ 运的运盘，中宫为 $n$，其他宫位按洛书轨迹顺飞。

飞星轨迹：中(5)->乾(6)->兑(7)->艮(8)->离(9)->坎(1)->坤(2)->震(3)->巽(4)

### 4.3 三元龙的数学定义

**定义（三元龙）**：三元龙将24山分为天元龙、地元龙、人元龙三类。

**定理（三元龙划分）**：24山的三元龙划分遵循"子午卯酉天元，辰戌丑未地元，寅申巳亥人元"的规则。

## 五、三元九运的动态演化模型

### 5.1 运星更替的离散动力系统

**定义（运星演化映射）**：运星演化 $F: \{1, \ldots, 9\} 	o \{1, \ldots, 9\}$ 为：

$$F(n) = (n \mod 9) + 1$$

**定理（演化周期性）**：$F^9(n) = n$，即运星演化以9为周期。

### 5.2 三元更替的动力学

**定义（三元演化映射）**：三元演化 $G: \{	ext{上}, 	ext{中}, 	ext{下}\} 	o \{	ext{上}, 	ext{中}, 	ext{下}\}$ 为：

$$G(	ext{上}) = 	ext{中}, \quad G(	ext{中}) = 	ext{下}, \quad G(	ext{下}) = 	ext{上}$$

**定理（三元周期）**：$G^3 = 	ext{id}$，即三元以3为周期。

### 5.3 联合演化模型

**定义（联合演化）**：三元九运的联合演化 $\mathcal{E}: \{	ext{上}, 	ext{中}, 	ext{下}\} 	imes \{1, \ldots, 9\} 	o \{	ext{上}, 	ext{中}, 	ext{下}\} 	imes \{1, \ldots, 9\}$ 为：

$$\mathcal{E}(	au, n) = egin{cases}
(	au, F(n)) & n < 9 \
(G(	au), 1) & n = 9
\end{cases}$$

## 六、三元九运计算的高级算法

def get_yun_number(year):
    base_year = 1864
    delta = year - base_year
    period = delta % 180
    return (period // 20) + 1
