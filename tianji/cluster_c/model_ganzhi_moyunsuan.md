# 天干地支的模运算表示系统

## 一、问题定义

天干地支系统作为中国古代最基础的符号体系，其数理本质可完全由模运算刻画。本节建立天干地支的严格代数表示，推导其运算规则，并分析模运算框架下的各类衍生性质。

## 二、天干系统的模10代数

### 2.1 基本定义

设天干集合 $T = \{甲, 乙, 丙, 丁, 戊, 己, 庚, 辛, 壬, 癸\}$，建立同构映射：

$$\phi_T: T \to \mathbb{Z}_{10}$$

$$\phi_T(甲) = 0, \phi_T(乙) = 1, \ldots, \phi_T(癸) = 9$$

### 2.2 天干的加法运算

定义天干加法为模10加法：

$$t_1 \oplus_T t_2 = \phi_T^{-1}((\phi_T(t_1) + \phi_T(t_2)) \bmod 10)$$

**示例**：丙 + 戊 = ？

$$\phi_T(丙) = 2, \phi_T(戊) = 4$$

$$(2 + 4) \bmod 10 = 6$$

$$\phi_T^{-1}(6) = 庚$$

故丙 $\oplus_T$ 戊 = 庚。

### 2.3 天干的群结构

**定理**：$(T, \oplus_T)$ 构成10阶循环群，与 $(\mathbb{Z}_{10}, +)$ 同构。

**证明**：

- 封闭性：模10加法封闭
- 结合律：继承整数加法结合律
- 单位元：甲（对应0）
- 逆元：$t^{-1} = \phi_T^{-1}((10 - \phi_T(t)) \bmod 10)$
- 交换律：继承整数加法交换律

生成元为乙（对应1），因为：

$$\langle 乙 \rangle = \{乙, 丙, 丁, 戊, 己, 庚, 辛, 壬, 癸, 甲\} = T$$

### 2.4 天干的乘法运算

定义天干乘法为模10乘法：

$$t_1 \otimes_T t_2 = \phi_T^{-1}((\phi_T(t_1) \cdot \phi_T(t_2)) \bmod 10)$$

**注意**：模10乘法不构成群，因为存在零因子（$2 \times 5 = 0 \pmod{10}$）。

## 三、地支系统的模12代数

### 3.1 基本定义

设地支集合 $D = \{子, 丑, 寅, 卯, 辰, 巳, 午, 未, 申, 酉, 戌, 亥\}$，建立同构映射：

$$\phi_D: D \to \mathbb{Z}_{12}$$

$$\phi_D(子) = 0, \phi_D(丑) = 1, \ldots, \phi_D(亥) = 11$$

### 3.2 地支的加法运算

定义地支加法为模12加法：

$$d_1 \oplus_D d_2 = \phi_D^{-1}((\phi_D(d_1) + \phi_D(d_2)) \bmod 12)$$

**示例**：寅 + 巳 = ？

$$\phi_D(寅) = 2, \phi_D(巳) = 5$$

$$(2 + 5) \bmod 12 = 7$$

$$\phi_D^{-1}(7) = 未$$

故寅 $\oplus_D$ 巳 = 未。

### 3.3 地支的群结构

**定理**：$(D, \oplus_D)$ 构成12阶循环群，与 $(\mathbb{Z}_{12}, +)$ 同构。

生成元为丑（对应1），因为：

$$\langle 丑 \rangle = \{\text{全部12个地支}\} = D$$

### 3.4 地支的乘法结构

模12乘法同样存在零因子（$3 \times 4 = 0 \pmod{12}$），不构成群。

但可逆元构成乘法群：

$$\mathbb{Z}_{12}^* = \{1, 5, 7, 11\}$$

对应地支：丑、辰、未、亥。

## 四、干支组合的模运算系统

### 4.1 六十甲子的模60表示

六十甲子序列的序号 $k \in \mathbb{Z}_{60}$ 满足：

$$k \equiv t \pmod{10}$$

$$k \equiv d \pmod{12}$$

其中 $t = \phi_T(\text{天干})$，$d = \phi_D(\text{地支})$。

### 4.2 存在性条件

**定理**：干支组合 $(t, d)$ 存在当且仅当：

$$t \equiv d \pmod{\gcd(10, 12)}$$

即：

$$t \equiv d \pmod{2}$$

**证明**：这是中国剩余定理在模数不互素时的直接推论。

### 4.3 通解公式

当 $t \equiv d \pmod{2}$ 时，解为：

$$k = 6t + 55d \pmod{60}$$

或等价地：

$$k = 6t - 5d \pmod{60}$$

**推导**：

设 $k = at + bd$，需满足：

$$at + bd \equiv t \pmod{10} \Rightarrow (a-1)t + bd \equiv 0 \pmod{10}$$

$$at + bd \equiv d \pmod{12} \Rightarrow at + (b-1)d \equiv 0 \pmod{12}$$

取 $a = 6, b = -5$：

第一式：$5t - 5d = 5(t-d) \equiv 0 \pmod{10}$（因 $t-d$ 为偶数）

第二式：$6t - 6d = 6(t-d) \equiv 0 \pmod{12}$（因 $t-d$ 为偶数）

验证通过。

## 五、模运算的术数应用

### 5.1 年份到甲子的转换

给定公历年份 $Y$，计算对应甲子：

**算法**：

$$k = (Y - 4) \bmod 60$$

（注：1984年为甲子年，$1984 - 4 = 1980$，$1980 \bmod 60 = 0$）

天干索引：$t = k \bmod 10$

地支索引：$d = k \bmod 12$

**示例**：计算2024年的甲子

$$k = (2024 - 4) \bmod 60 = 2020 \bmod 60 = 40$$

$$t = 40 \bmod 10 = 0 \Rightarrow 甲$$

$$d = 40 \bmod 12 = 4 \Rightarrow 辰$$

故2024年为甲辰年，验证正确。

### 5.2 甲子到年份的转换

给定甲子序号 $k$，计算最近的公历年份：

$$Y = 4 + k + 60n$$

其中 $n$ 为整数，使得 $Y$ 落在目标范围内。

### 5.3 月建的模运算

地支与月份的对应（以寅月为正月）：

$$\text{月建} = \phi_D^{-1}((n + 1) \bmod 12)$$

其中 $n$ 为阴历月份（1-12）。

正月（$n=1$）：$(1+1) \bmod 12 = 2$ = 寅

十二月（$n=12$）：$(12+1) \bmod 12 = 1$ = 丑

### 5.4 时辰的模运算

地支与时辰的对应：

$$\text{时辰} = \phi_D^{-1}((h + 1) \div 2 \bmod 12)$$

其中 $h$ 为24小时制小时数（0-23）。

## 六、模运算的代数性质

### 6.1 同余关系的等价性

**定义**：$a \equiv b \pmod{n}$ 当且仅当 $n \mid (a - b)$。

**性质**：

- 自反性：$a \equiv a \pmod{n}$
- 对称性：$a \equiv b \pmod{n} \Rightarrow b \equiv a \pmod{n}$
- 传递性：$a \equiv b \pmod{n}, b \equiv c \pmod{n} \Rightarrow a \equiv c \pmod{n}$

### 6.2 模运算的运算律

**加法性质**：

$$(a + b) \bmod n = ((a \bmod n) + (b \bmod n)) \bmod n$$

**乘法性质**：

$$(a \cdot b) \bmod n = ((a \bmod n) \cdot (b \bmod n)) \bmod n$$

**幂运算性质**：

$$a^b \bmod n = ((a \bmod n)^b) \bmod n$$

### 6.3 欧拉定理与费马小定理

**欧拉定理**：若 $\gcd(a, n) = 1$，则：

$$a^{\varphi(n)} \equiv 1 \pmod{n}$$

**费马小定理**（欧拉定理特例）：若 $p$ 为素数，则：

$$a^{p-1} \equiv 1 \pmod{p}$$

**应用于六十甲子**：

对任意与60互素的 $a$：

$$a^{16} \equiv 1 \pmod{60}$$

因 $\varphi(60) = 16$。

## 七、模运算的算法实现

### 7.1 高效模幂算法

```
算法：ModularExponentiation
输入：底数 a，指数 e，模数 n
输出：a^e mod n

1. result = 1
2. base = a mod n
3. 当 e > 0：
   a. 如果 e 是奇数：
      result = (result * base) mod n
   b. base = (base * base) mod n
   c. e = e / 2（整数除法）
4. 返回 result
```

**时间复杂度**：$O(\log e)$

### 7.2 扩展欧几里得算法

```
算法：ExtendedGCD
输入：整数 a, b
输出：(g, x, y) 满足 ax + by = g = gcd(a, b)

1. 如果 b = 0：
   返回 (a, 1, 0)
2. (g, x1, y1) = ExtendedGCD(b, a mod b)
3. x = y1
4. y = x1 - (a // b) * y1
5. 返回 (g, x, y)
```

**应用于六十甲子**：求解 $10x + 12y = \gcd(10, 12) = 2$

运行算法得：$x = -1, y = 1$，即 $10 \times (-1) + 12 \times 1 = 2$。

## 八、精度分析

### 8.1 整数溢出分析

在32位整数系统中：

- 最大正值：$2^{31} - 1 = 2147483647$
- 六十甲子运算的最大中间值：$59 \times 59 = 3481$

远小于溢出阈值，**无溢出风险**。

### 8.2 模运算的精确性

模运算在整数范围内**完全精确**，无舍入误差。

### 8.3 边界条件

- $k = 0$：甲子
- $k = 59$：癸亥
- $k = 60$：回到甲子（周期验证）

## 九、应用示例

### 9.1 计算两个甲子之间的时间差

给定甲子 $G_1$（序号 $k_1$）和 $G_2$（序号 $k_2$），时间差为：

$$\Delta t = (k_2 - k_1) \bmod 60$$

**示例**：从甲子到甲午

$$k_1 = 0, k_2 = 30$$

$$\Delta t = (30 - 0) \bmod 60 = 30$$

即30年（或30月、30日、30时）。

### 9.2 甲子序列的等差子序列

取步长 $s$ 满足 $\gcd(s, 60) = 1$，则序列：

$$k, (k + s) \bmod 60, (k + 2s) \bmod 60, \ldots$$

遍历全部60个甲子。

**示例**：步长 $s = 7$

序列：0, 7, 14, 21, 28, 35, 42, 49, 56, 3, 10, ...

对应甲子：甲子、庚午、丁丑、甲申、辛卯、戊戌、乙巳、壬子、己未、丙寅、甲戌...

## 十、可衍生研究方向

### 10.1 假设生成：模运算到p-adic数的映射

六十甲子的模结构可嵌入p-adic数系统，其中 $p = 2, 3, 5$（60的素因子）。这可能为干支系统赋予非阿基米德分析的解释框架。

### 10.2 假设生成：模运算到量子计算的映射

天干（模10）和地支（模12）可分别用量子比特表示：

- 天干：$\lceil \log_2 10 \rceil = 4$ 个量子比特
- 地支：$\lceil \log_2 12 \rceil = 4$ 个量子比特

六十甲子的量子态可表示为8量子比特的纠缠态，量子叠加可能对应"多重时间线"的术数概念。
