# 玄空风水挨星飞星递推模型

## 一、挨星飞星的概念体系

### 1.1 挨星的数学定义

挨星是玄空风水中描述星曜在九宫中动态分布的核心概念。从数学视角，挨星是一个从时间到九宫飞星分布的映射。

**定义（挨星空间）**：挨星空间 $\mathcal{A}$ 定义为九宫位置与九星值的组合集合：

$$\mathcal{A} = \{(p, s) : p \in \{1, \ldots, 9\}, s \in \{1, \ldots, 9\}\}$$

**定义（挨星映射）**：挨星映射 $lpha: \mathbb{N} 	imes \{1, \ldots, 9\} 	o \{1, \ldots, 9\}$ 定义为：在时间 $t$、宫位 $p$ 的挨星值。

### 1.2 飞星的递推规则

**定义（顺飞规则）**：顺飞时，星曜按洛书轨迹依次递增：

$$lpha(t, p_{i+1}) = (lpha(t, p_i) \mod 9) + 1$$

其中飞星顺序为：中(5)->乾(6)->兑(7)->艮(8)->离(9)->坎(1)->坤(2)->震(3)->巽(4)

**定义（逆飞规则）**：逆飞时，星曜按洛书轨迹依次递减：

$$lpha(t, p_{i+1}) = (lpha(t, p_i) - 2) \mod 9 + 1$$

### 1.3 中宫星的确定

**定义（中宫星）**：中宫星 $lpha(t, 5)$ 由运期、年、月、日、时等因素决定。

**定理（运盘中宫）**：第 $n$ 运的运盘中宫星为 $n$。

**定理（年盘中宫）**：某年的年盘中宫星由该年干支决定。

## 二、挨星飞星的递推模型

### 2.1 运盘挨星递推

**算法（运盘挨星递推）**：

输入：运数 $n \in \{1, \ldots, 9\}$

1. 中宫星：$s_5 = n$
2. 顺飞各宫：
   - 乾六宫：$s_6 = (n \mod 9) + 1$
   - 兑七宫：$s_7 = ((n+1) \mod 9) + 1$
   - ...

**定理（运盘公式）**：运盘宫位 $p$ 的挨星为：

$$s_p = ((n + d(p) - 1) \mod 9) + 1$$

其中 $d(p)$ 为从中心到宫位 $p$ 的飞星步数。

### 2.2 山盘挨星递推

**定义（山盘）**：山盘由坐山星入中宫顺飞或逆飞决定。

**定理（山盘顺逆判定）**：阳山顺飞，阴山逆飞。

**阳山**：乾、坤、艮、巽、甲、丙、庚、壬、子、寅、辰、午、申、戌
**阴山**：乙、丁、辛、癸、丑、卯、巳、未、酉、亥

### 2.3 向盘挨星递推

**定义（向盘）**：向盘由向首星入中宫顺飞或逆飞决定。

**定理（向盘顺逆判定）**：阳向顺飞，阴向逆飞。

### 2.4 三元龙的顺逆规则

**定义（三元龙顺逆）**：
- 天元龙（子午卯酉）：阳顺阴逆
- 地元龙（辰戌丑未）：阳顺阴逆
- 人元龙（寅申巳亥）：阳顺阴逆

## 三、挨星飞星的矩阵表示

### 3.1 飞星转移矩阵

**定义（顺飞转移矩阵）**：顺飞转移矩阵 $T_{	ext{顺}}$ 为 $9 	imes 9$ 的置换矩阵。

**定义（逆飞转移矩阵）**：逆飞转移矩阵 $T_{	ext{逆}}$ 为 $T_{	ext{顺}}$ 的逆矩阵。

### 3.2 挨星分布的向量表示

**定义（挨星向量）**：某盘的挨星分布可表示为9维向量：

$$\mathbf{s} = (s_1, s_2, \ldots, s_9)^T$$

**定理（挨星递推公式）**：从初始中宫星 $s_0$ 出发，挨星向量为：

$$\mathbf{s} = s_0 \cdot \mathbf{1} + T \cdot \mathbf{d}$$

其中 $\mathbf{d}$ 为步数向量，$T$ 为转移矩阵。

## 四、挨星飞星的周期分析

### 4.1 运盘周期

**定理（运盘周期）**：运盘以9运为周期，即第 $n$ 运与第 $n+9$ 运的运盘相同。

### 4.2 年盘周期

**定理（年盘周期）**：年盘以60年为周期（干支周期）。

### 4.3 月盘周期

**定理（月盘周期）**：月盘以12个月为周期。

### 4.4 日盘周期

**定理（日盘周期）**：日盘以60日为周期（干支周期）。

### 4.5 时盘周期

**定理（时盘周期）**：时盘以12时辰为周期。

## 五、挨星飞星的综合计算模型

### 5.1 多盘叠加模型

**定义（综合盘）**：综合盘是运盘、山盘、向盘等多盘的叠加。

**定理（综合盘公式）**：综合盘某宫位的挨星为：

$$S_{	ext{综合}}(p) = (S_{	ext{运}}(p), S_{	ext{山}}(p), S_{	ext{向}}(p))$$

### 5.2 挨星的吉凶判断

**定义（挨星吉凶）**：挨星的吉凶由其五行属性与宫位五行的生克关系决定。

**定理（吉凶公式）**：设挨星五行为 $w_s$，宫位五行为 $w_p$，则：

## 六、挨星飞星计算的高级算法

### 6.1 查表法

```python
# 飞星顺序表（从中宫开始顺飞）
FEIXING_ORDER = [5, 6, 7, 8, 9, 1, 2, 3, 4]

# 宫位索引映射
POSITION_INDEX = {
    1: 5,  # 坎一宫
    2: 6,  # 坤二宫
    3: 7,  # 震三宫
    4: 8,  # 巽四宫
    5: 0,  # 中五宫
    6: 1,  # 乾六宫
    7: 2,  # 兑七宫
    8: 3,  # 艮八宫
    9: 4   # 离九宫
}

def compute_feixing(zhonggong_xing, shunfei=True):
    """计算飞星盘"""
    result = {}
    for pos in range(1, 10):
        idx = POSITION_INDEX[pos]
        if shunfei:
            star = ((zhonggong_xing + idx - 1) % 9) + 1
        else:
            star = ((zhonggong_xing - idx - 1) % 9) + 1
        result[pos] = star
    return result
```

### 6.2 模运算法

```python
def compute_feixing_fast(zhonggong_xing, positions, shunfei=True):
    """快速计算飞星"""
    sign = 1 if shunfei else -1
    return [((zhonggong_xing + sign * i - 1) % 9) + 1 for i in range(9)]
```

## 七、挨星飞星模型的扩展应用

### 7.1 在阳宅布局中的应用

**定理（布局原则）**：阳宅的床位、灶位、门位应与挨星的吉方相配合。

### 7.2 在阴宅风水中的应用

**定理（阴宅原则）**：阴宅的坐向应与山盘挨星的旺方相配合。

### 7.3 挨星飞星的统计特性

**定理（挨星均匀分布）**：在180年周期内，每个挨星在每个宫位出现的频率相等。
