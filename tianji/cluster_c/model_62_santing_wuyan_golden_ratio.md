# 三停五眼的黄金分割模型

## 1. 黄金分割的数学基础

黄金分割比例 $\phi = \frac{1+\sqrt{5}}{2} \approx 1.618$ 是自然界和艺术中广泛存在的比例。面相学中的三停五眼与黄金分割存在深刻联系。

### 1.1 黄金分割的定义

线段黄金分割：点 $C$ 将线段 $AB$ 分为黄金分割当：

$$\frac{AC}{CB} = \frac{AB}{AC} = \phi$$

### 1.2 黄金分割的代数性质

$$\phi^2 = \phi + 1$$

$$\frac{1}{\phi} = \phi - 1$$

$$\phi^n = F_n \phi + F_{n-1}$$

其中 $F_n$ 为Fibonacci数列。

### 1.3 黄金矩形与黄金螺旋

黄金矩形：长宽比为 $\phi$ 的矩形

黄金螺旋：在黄金矩形中连续内切四分之一圆弧形成的对数螺旋

$$r = ae^{b\theta}, \quad b = \frac{\ln \phi}{\pi/2}$$

## 2. 三停的黄金分割分析

### 2.1 三停的定义

**上停**：发际线到眉心

**中停**：眉心到鼻底

**下停**：鼻底到下巴

### 2.2 理想三停比例

理想三停等分：$H_1 : H_2 : H_3 = 1 : 1 : 1$

黄金分割变体：$H_1 : H_2 : H_3 = 1 : \phi : 1$ 或 $1 : 1 : \phi$

### 2.3 三停黄金指数

定义三停黄金指数：

$$G_{三停} = \frac{1}{3}\left(g\left(\frac{H_1}{H_2}\right) + g\left(\frac{H_2}{H_3}\right) + g\left(\frac{H_1}{H_3}\right)\right)$$

其中 $g(r) = e^{-(r-\phi)^2/2\sigma^2}$ 为黄金比例接近度函数。

## 3. 五眼的黄金分割分析

### 3.1 五眼的定义

面部宽度分为五等份：

- 左太阳穴到左眼外角
- 左眼宽度
- 两眼间距
- 右眼宽度
- 右眼外角到右太阳穴

### 3.2 五眼黄金比例

理想五眼等分：$W_1 : W_2 : W_3 : W_4 : W_5 = 1 : 1 : 1 : 1 : 1$

黄金分割变体：$W_2 : W_3 : W_4 = 1 : \phi : 1$（眼距与眼宽比）

### 3.3 五眼黄金指数

$$G_{五眼} = \frac{1}{4}\sum_{i=1}^{4} g\left(\frac{W_i}{W_{i+1}}\right)$$

## 4. 面部黄金网格

### 4.1 Phi网格

将面部划分为基于 $\phi$ 的网格：

水平线位置：$y_k = H \cdot \frac{\phi^{k-1}}{\sum_{i=0}^{n-1}\phi^i}$

垂直线位置：类似定义

### 4.2 黄金分割点

面部关键黄金分割点：

- 眉心：全脸的 $1/\phi$ 处
- 鼻底：全脸的 $1/\phi^2$ 处
- 嘴角：面宽的 $1/\phi$ 处

### 4.3 黄金三角形

面部黄金三角形：

- 顶点：发际中点、下巴、两耳
- 底边与腰之比为 $\phi$

## 5. 面部黄金比例的综合评估

### 5.1 综合黄金指数

$$G_{total} = w_1 G_{三停} + w_2 G_{五眼} + w_3 G_{轮廓} + w_4 G_{五官}$$

### 5.2 黄金比例符合度等级

- 95-100：完美黄金比例
- 85-94：优秀
- 75-84：良好
- 60-74：一般
- <60：偏离

### 5.3 黄金比例偏差分析

计算各部位与黄金比例的偏差：

$$\Delta_i = \frac{r_i - \phi}{\phi} \times 100\%$$

## 6. 黄金分割与面相吉凶

### 6.1 黄金比例与审美

心理学研究表明，接近黄金比例的面部被认为更具吸引力。

### 6.2 面相学中的黄金比例

传统面相学认为：

- 三停均匀：一生平顺
- 五眼协调：人际关系和谐
- 轮廓黄金：福禄双全

### 6.3 黄金比例的统计学验证

收集大量样本，验证黄金比例与面相判断的相关性：

$$\rho = \frac{Cov(G_{total}, Score)}{\sigma_G \sigma_{Score}}$$

## 7. 黄金分割的计算方法

### 7.1 精确计算

已知两点 $A, B$，黄金分割点 $C$：

$$C = A + \frac{1}{\phi}(B - A)$$

### 7.2 迭代逼近

Fibonacci逼近：

$$\frac{F_{n+1}}{F_n} \to \phi \text{ as } n \to \infty$$

### 7.3 连分数表示

$$\phi = 1 + \frac{1}{1 + \frac{1}{1 + \frac{1}{1 + \cdots}}}$$

## 8. 结论

黄金分割理论为面相学中的三停五眼提供了精确的数学框架。黄金比例、Phi网格、黄金指数等概念与面相学中的面部比例评估建立了严格的对应关系。该模型可用于面部美学的定量分析和面相判断的客观化。
