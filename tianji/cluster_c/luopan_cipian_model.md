# 罗盘磁偏角修正数学模型

## 一、磁偏角的概念体系

### 1.1 磁偏角的数学定义

磁偏角是磁北方向与真北方向之间的夹角。

**定义（磁偏角）**：磁偏角 $\delta$ 定义为：

$$\delta = 	heta_{	ext{磁北}} - 	heta_{	ext{真北}}$$

其中：
- $\delta > 0$：磁北偏东（东偏）
- $\delta < 0$：磁北偏西（西偏）
- $\delta = 0$：磁北与真北重合

### 1.2 磁偏角的时空变化

**定义（磁偏角函数）**：磁偏角是地理位置和时间的高阶函数：

$$\delta = f(\lambda, \phi, t)$$

其中 $\lambda$ 为经度，$\phi$ 为纬度，$t$ 为时间。

### 1.3 磁偏角的长期变化

**定理（磁偏角长期变化）**：磁偏角存在长期变化趋势（secular variation），年变化率约为 $0.1°$ 到 $0.5°$。

## 二、磁偏角计算的几何模型

其中：
- $a$ 为地球半径
- $g_n^m, h_n^m$ 为高斯系数
- $P_n^m$ 为连带勒让德函数

### 2.2 磁偏角的计算公式

**定理（磁偏角公式）**：磁偏角可通过磁场分量计算：

$$\delta = rctan2(Y, X)$$

其中 $X, Y$ 为磁场北向和东向水平分量。

## 三、磁偏角修正的代数模型

### 3.1 真方位角计算

**定义（真方位角）**：真方位角 $	heta_{	ext{真}}$ 与磁方位角 $	heta_{	ext{磁}}$ 的关系为：

$$	heta_{	ext{真}} = 	heta_{	ext{磁}} + \delta$$

### 3.2 磁偏角修正算法

**算法（磁偏角修正）**：

输入：磁方位角 $	heta_{	ext{磁}}$，磁偏角 $\delta$

1. 计算真方位角：$	heta_{	ext{真}} = 	heta_{	ext{磁}} + \delta$
2. 规范化到 $[0, 360)$：$	heta_{	ext{真}} = 	heta_{	ext{真}} \mod 360$

输出：真方位角 $	heta_{	ext{真}}$

### 3.3 反向修正

**算法（磁方位角计算）**：

输入：真方位角 $	heta_{	ext{真}}$，磁偏角 $\delta$

1. 计算磁方位角：$	heta_{	ext{磁}} = 	heta_{	ext{真}} - \delta$
2. 规范化到 $[0, 360)$：$	heta_{	ext{磁}} = 	heta_{	ext{磁}} \mod 360$

输出：磁方位角 $	heta_{	ext{磁}}$

## 五、磁偏角修正的误差分析

### 5.1 误差来源

**定义（误差来源）**：
1. 磁偏角模型误差
2. 时间变化误差
3. 局部磁场异常
4. 罗盘测量误差

### 5.2 误差传播

**定理（误差传播公式）**：设磁方位角误差为 $\sigma_{	heta}$，磁偏角误差为 $\sigma_{\delta}$，则真方位角误差为：

$$\sigma_{	ext{真}} = \sqrt{\sigma_{	heta}^2 + \sigma_{\delta}^2}$$

### 5.3 精度控制

**定义（精度要求）**：风水测量通常要求方位精度在 $0.5°$ 以内。

**定理（精度控制条件）**：为满足 $0.5°$ 精度，需要：

$$\sigma_{	heta}^2 + \sigma_{\delta}^2 \leq 0.25$$

def correct_magnetic_to_true(magnetic_azimuth, city):
    """磁方位角修正为真方位角"""
    delta = CIPIAN_TABLE.get(city, -4.0)  # 默认-4度

    return true_azimuth % 360

## 七、磁偏角模型的扩展应用

### 7.1 在风水测量中的应用

**定理（风水测量原则）**：风水测量应使用真方位角，需对罗盘读数进行磁偏角修正。

### 7.2 在航海导航中的应用

**定理（航海导航原则）**：航海导航需根据当前位置的磁偏角修正航向。

### 7.3 在航空导航中的应用

**定理（航空导航原则）**：航空导航使用真方位角，磁罗盘读数需修正磁偏角。
