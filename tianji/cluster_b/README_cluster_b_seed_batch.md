## 可衍生研究方向

### 历法矛盾分析（Conflict Analysis）

1. **conflict_analysis_qimendunjia_mijiquanshu_历法矛盾.md**
   - 研究内容：《奇门遁甲秘笈全书》卷六与卷七关于置闰法与拆补法的历法逻辑矛盾
   - 矛盾点：置闰法主张重复节气，拆补法主张均匀分配，两种方法得出的局数可能不同

2. **conflict_analysis_qimendunjia_tongzong_流派矛盾.md**
   - 研究内容：《奇门遁甲统宗》收录的置闰法、拆补法、茅山法之间的逻辑矛盾
   - 矛盾点：茅山法不考虑节气，与置闰法、拆补法的逻辑基础完全不同

### 比较研究（Comparative Study）

3. **comparative_study_zangshu_vs_qingnangjing_气的理论.md**
   - 研究内容：《葬书》与《青囊经》"气"概念的理论差异
   - 差异点：《葬书》强调"生气"的聚散，《青囊经》强调"理气"的运动规律

4. **comparative_study_qingnangaoyu_vs_tianyujing_玄空理论.md**
   - 研究内容：《青囊奥语》与《天玉经》玄空风水理论的异同
   - 研究价值：两部典籍均为杨筠松所著（或相传），可对比分析玄空风水理论的演变

5. **comparative_study_hanlongjing_vs_yilongjing_形法体系.md**
   - 研究内容：《撼龙经》与《疑龙经》形法风水体系的互补性
   - 研究价值：《撼龙经》讲寻龙，《疑龙经》讲辨龙，两者共同构成形法风水学的完整体系
