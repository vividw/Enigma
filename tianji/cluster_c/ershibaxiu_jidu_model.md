# 二十八宿距度计算模型

## 一、二十八宿的概念体系

### 1.1 二十八宿的数学定义

二十八宿是中国古代天文学中将黄道附近天区划分为28个星宿的坐标系统。

**定义（二十八宿集合）**：二十八宿集合 $\mathcal{X}$ 定义为：

$$\mathcal{X} = \{角, 亢, 氐, 房, 心, 尾, 箕, 斗, 牛, 女, 虚, 危, 室, 壁, 奎, 娄, 胃, 昴, 毕, 觜, 参, 井, 鬼, 柳, 星, 张, 翼, 轸\}$$

### 1.2 距度的数学定义

**定义（距度）**：距度是相邻两宿之间的黄经差。

**定义（距度函数）**：距度函数 $d: \mathcal{X} 	o \mathbb{R}^+$ 定义为：

$$d(x_i) = \lambda(x_{i+1}) - \lambda(x_i)$$

其中 $\lambda(x)$ 为宿的赤经或黄经。

### 1.3 二十八宿的方位划分

**定义（四象）**：二十八宿分为四象，每象7宿：

- 东方青龙：角、亢、氐、房、心、尾、箕
- 北方玄武：斗、牛、女、虚、危、室、壁
- 西方白虎：奎、娄、胃、昴、毕、觜、参
- 南方朱雀：井、鬼、柳、星、张、翼、轸

## 三、距度计算的天文学基础

### 3.1 赤经与黄经的关系

**定义（赤经）**：赤经 $lpha$ 是天体在天赤道坐标系中的经度。

**定义（黄经）**：黄经 $\lambda$ 是天体在黄道坐标系中的经度。

**定理（坐标转换）**：赤经与黄经的转换公式为：

$$	an \lambda = rac{\sin lpha \cos \epsilon + 	an \delta \sin \epsilon}{\cos lpha}$$

其中 $\epsilon$ 为黄赤交角，$\delta$ 为赤纬。

### 3.2 岁差对距度的影响

**定义（岁差）**：岁差是春分点沿黄道的西移现象。

**定理（岁差公式）**：岁差导致的黄经变化为：

其中 $T$ 为从历元起的年数。

## 五、距度计算的代数模型

### 5.1 距度的模运算表示

**定义（距度向量）**：二十八宿距度可表示为28维向量：

$$\mathbf{d} = (d_1, d_2, \ldots, d_{28})^T$$

**定理（距度和）**：距度向量的分量和为：

$$\sum_{i=1}^{28} d_i = 365.25°$$

### 5.2 距度的矩阵表示

**定义（距度矩阵）**：距度矩阵 $D$ 为 $28 	imes 28$ 的循环矩阵：

$$D_{i,j} = d_{(i+j-2) \mod 28 + 1}$$

### 5.3 距度的累积计算

**定义（累积距度）**：从第1宿到第 $k$ 宿的累积距度为：

$$D_k = \sum_{i=1}^{k} d_i$$

**定理（累积距度公式）**：任意宿的黄经为：

$$\lambda(x_k) = \lambda(x_1) + D_{k-1}$$

## 六、距度计算的高级算法

### 6.1 查表法

```python
# 二十八宿距度表（先秦数据）
XIU_DU_TABLE = {
    "角": 12, "亢": 9, "氐": 15, "房": 5, "心": 5, "尾": 18, "箕": 11,
    "斗": 26, "牛": 8, "女": 12, "虚": 10, "危": 17, "室": 16, "壁": 9,
    "奎": 16, "娄": 12, "胃": 14, "昴": 11, "毕": 16, "觜": 2, "参": 9,
    "井": 33, "鬼": 4, "柳": 15, "星": 7, "张": 18, "翼": 18, "轸": 17
}

XIU_ORDER = ["角", "亢", "氐", "房", "心", "尾", "箕", "斗", "牛", "女", 
             "虚", "危", "室", "壁", "奎", "娄", "胃", "昴", "毕", "觜", 
             "参", "井", "鬼", "柳", "星", "张", "翼", "轸"]

def get_xiu_longitude(xiu_name, base_longitude=0):
    """计算某宿的黄经"""
    idx = XIU_ORDER.index(xiu_name)
    longitude = base_longitude
    for i in range(idx):
        longitude += XIU_DU_TABLE[XIU_ORDER[i]]
    return longitude % 365.25
```

### 6.2 累积计算法

```python
def calculate_cumulative_xiudu():
    """计算累积距度"""
    cumulative = [0]
    for xiu in XIU_ORDER:
        cumulative.append(cumulative[-1] + XIU_DU_TABLE[xiu])
    return cumulative
```

### 6.3 岁差修正

```python
def correct_precession(longitude, years_from_epoch):
    """岁差修正"""
    precession_rate = 50.291 / 3600  # 度/年
    return (longitude + precession_rate * years_from_epoch) % 360
```
