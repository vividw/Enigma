# 奇门遁甲用神选取的优化

## 1. 用神选取的数学模型

奇门遁甲中用神选取是关键的决策问题。通过建立优化模型，可以系统地分析用神选取的策略。

### 1.1 用神候选集

奇门盘中的用神候选：

$$C = \{天盘九星, 地盘九宫, 八门, 八神, 天干, 地支\}$$

### 1.2 用神属性向量

每个候选用神具有属性向量：

$$\vec{a}(c) = (五行, 方位, 吉凶, 生克, 旺衰, \ldots)$$

### 1.3 用神评分函数

用神评分：

$$Score(c) = \vec{w}^T \vec{a}(c)$$

其中 $\vec{w}$ 为权重向量。

## 2. 用神选取的约束条件

### 2.1 用神唯一性

每个用神类别只能选一个：

$$\sum_{c \in C_i} x_c = 1, \quad \forall i$$

其中 $x_c \in \{0, 1\}$ 表示是否选取 $c$。

### 2.2 用神相容性

选取的用神之间需相容：

$$x_c + x_{c'} \leq 1, \quad \forall (c, c') \in Incompatible$$

### 2.3 用神必要性

某些用神必须选取：

$$x_c = 1, \quad \forall c \in Required$$

## 3. 用神选取的整数规划

### 3.1 目标函数

最大化用神总评分：

$$\max \sum_{c \in C} Score(c) \cdot x_c$$

### 3.2 约束条件

$$\sum_{c \in C_i} x_c = 1, \quad \forall i$$

$$x_c + x_{c'} \leq 1, \quad \forall (c, c') \in Incompatible$$

$$x_c \in \{0, 1\}, \quad \forall c \in C$$

### 3.3 求解方法

分支定界法、割平面法等求解整数规划。

## 4. 用神选取的动态规划

### 4.1 子问题定义

$dp[i][S]$：考虑前 $i$ 类用神，已选集合为 $S$ 时的最大评分。

### 4.2 状态转移

$$dp[i][S \cup \{c\}] = \max(dp[i][S \cup \{c\}], dp[i-1][S] + Score(c))$$

### 4.3 复杂度分析

时间复杂度：$O(|C| \cdot 2^{|C|})$

空间复杂度：$O(2^{|C|})$

## 5. 用神选取的启发式算法

### 5.1 贪心算法

每步选取当前最优用神：

```
算法贪心:
1. 按评分排序候选用神
2. for each 用神类别:
3.     选取评分最高且相容的用神
4. return 选取的用神集合
```

### 5.2 局部搜索

从初始解出发，进行局部改进：

- 交换：用一个神替换另一个
- 添加/删除：调整用神集合

### 5.3 模拟退火

随机扰动 + 概率接受：

$$P(accept) = \exp\left(\frac{\Delta Score}{T}\right)$$

## 6. 用神选取的多目标优化

### 6.1 多目标函数

- 最大化用神评分
- 最小化用神冲突
- 最大化用神覆盖

### 6.2 Pareto最优

Pareto前沿上的解：

$$\mathcal{P} = \{x : \nexists x' \text{ s.t. } f_i(x') \geq f_i(x), \forall i, \text{ 严格大于某 } i\}$$

### 6.3 NSGA-II算法

非支配排序遗传算法求解多目标优化。

## 7. 用神选取的机器学习

### 7.1 特征工程

用神特征：位置、五行、生克关系、历史准确率

### 7.2 分类模型

预测用神是否合适：

$$P(y=1 | \vec{x}) = \sigma(\vec{w}^T \vec{x} + b)$$

### 7.3 强化学习

用神选取作为序列决策问题：

- 状态：当前奇门盘
- 动作：选取用神
- 奖励：预测准确率

## 8. 结论

优化理论和机器学习为奇门遁甲用神选取提供了系统的数学方法。整数规划、动态规划、启发式算法、多目标优化等概念与奇门遁甲中的用神选取策略建立了精确的对应关系。该模型可用于用神选取的自动化和优化决策支持。
