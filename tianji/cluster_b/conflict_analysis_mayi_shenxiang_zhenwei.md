# 《麻衣神相》真伪诸说考证

## 一、问题的提出

### 1.1 《麻衣神相》的学术争议

《麻衣神相》是中国古代最著名的相术著作之一，但其作者和成书年代历来众说纷纭。关于《麻衣神相》的真伪，学术界存在重大争议：

**争议一：作者是否为麻衣道者**

传统观点认为，《麻衣神相》为五代宋初的麻衣道者所作。但麻衣道者的历史真实性存疑。

**争议二：是否为陈抟托名**

有学者认为，《麻衣神相》可能是北宋初年的陈抟托名麻衣道者所作。

**争议三：是否为后人伪托**

现代学者多认为，《麻衣神相》是后人伪托麻衣道者之名所作，其成书年代可能在明代。

### 1.2 真伪考证的学术意义

**文献学意义**

考证《麻衣神相》的真伪，有助于确定其成书年代和作者，是文献学研究的重要内容。

**思想史意义**

考证《麻衣神相》的真伪，有助于了解中国古代相术思想的发展脉络。

**文化史意义**

考证《麻衣神相》的真伪，有助于了解中国古代文化中的相术传统。

**陈抟生平**

陈抟（871-989），字图南，号扶摇子，五代宋初著名的道士。陈抟精通易学、相术，被后世尊为"陈抟老祖"。

**问题一：缺乏确证**

陈抟托名说缺乏确证，主要是推测。
