# 农历闰月计算的高精度算法

## 一、农历闰月的概念体系

### 1.1 朔望月的数学定义

朔望月是从一次新月到下一次新月的时间间隔。

**定义（朔望月长度）**：朔望月平均长度为：

$$T_{	ext{朔望}} = 29.530588 	ext{ 日}$$

**定义（朔望月周期）**：朔望月周期存在微小变化：

$$T_{	ext{朔望}}(t) = T_0 + \sum_{i} A_i \sin(\omega_i t + \phi_i)$$

### 1.2 回归年的数学定义

回归年是太阳连续两次经过春分点的时间间隔。

**定义（回归年长度）**：回归年平均长度为：

$$T_{	ext{回归}} = 365.24219878 	ext{ 日}$$

### 1.3 农历年的数学定义

农历年以朔望月为基础，通过设置闰月来协调与回归年的关系。

**定义（农历年长度）**：平年12个月，闰年13个月：

$$T_{	ext{农历年}} = egin{cases}
12 	imes T_{	ext{朔望}} pprox 354 	ext{ 日} & 	ext{平年} \
13 	imes T_{	ext{朔望}} pprox 384 	ext{ 日} & 	ext{闰年}
\end{cases}$$

## 二、闰月判定的数学模型

### 2.1 二十四节气与中气

**定义（二十四节气）**：二十四节气将回归年分为24等份，每份约15.22日。

**定义（中气）**：中气是二十四节气中的偶数位节气（雨水、春分、谷雨、小满、夏至、大暑、处暑、秋分、霜降、小雪、冬至、大寒）。

### 2.2 无中气置闰法则

**定义（无中气置闰）**：若某朔望月内不包含任何中气，则该月设为闰月。

**定理（闰月存在性）**：由于 $T_{	ext{朔望}} < T_{	ext{节气}}$，必然存在无中气的月份。

*证明*：朔望月约29.53日，节气间隔约30.44日，朔望月短于节气间隔，故存在某些朔望月不包含中气。$\square$

### 2.3 闰月位置的确定

**算法（闰月确定）**：

输入：农历年份

1. 计算该年各朔望月的朔日时刻
2. 计算该年各中气的时刻
3. 检查每个月是否包含中气
4. 若某月无中气，则该月为闰月

输出：闰月位置（若有）

## 三、高精度朔日计算模型

### 3.1 朔日计算的天文学基础

**定义（合朔时刻）**：合朔时刻是日月黄经相等的时刻。

**定理（合朔条件）**：设太阳黄经为 $\lambda_\odot$，月亮黄经为 $\lambda_\moon$，则合朔条件为：

$$\lambda_\odot = \lambda_\moon \pmod{360°}$$

### 3.2 太阳黄经计算

**定义（太阳黄经公式）**：太阳黄经可用以下公式计算：

$$\lambda_\odot = L_0 + 1.914666471 \sin(g) + 0.019994643 \sin(2g)$$

其中：
- $L_0 = 280.46646° + 36000.76983° \cdot T$
- $g = 357.52911° + 35999.05029° \cdot T$
- $T$ 为儒略世纪数

### 3.3 月亮黄经计算

**定义（月亮黄经公式）**：月亮黄经可用ELP-2000/82理论计算：

$$\lambda_\moon = \sum_{i} A_i \sin(\phi_i)$$

其中 $\phi_i$ 为各种周期的相位组合。

### 3.4 朔日迭代计算

**算法（朔日迭代）**：

输入：近似朔日 $t_0$

1. 计算太阳黄经 $\lambda_\odot(t_0)$
2. 计算月亮黄经 $\lambda_\moon(t_0)$
3. 计算差值：$\Delta\lambda = \lambda_\odot - \lambda_\moon$
4. 修正时刻：$t_1 = t_0 - rac{\Delta\lambda}{n_\odot - n_\moon}$
5. 重复直到 $|\Delta\lambda| < \epsilon$

输出：精确朔日时刻

## 四、中气计算的高精度模型

### 4.1 中气时刻的定义

**定义（中气时刻）**：中气时刻是太阳黄经等于特定值的时刻。

**定理（中气黄经）**：第 $k$ 个中气的太阳黄经为：

$$\lambda_k = 30° 	imes (k - 1) + 15°$$

其中 $k = 1, 2, \ldots, 12$ 对应12个中气。

### 4.2 中气时刻的迭代计算

**算法（中气迭代）**：

输入：中气序号 $k$，近似时刻 $t_0$

1. 计算目标黄经：$\lambda_{	ext{目标}} = 30° 	imes (k - 1) + 15°$
2. 计算太阳黄经 $\lambda_\odot(t_0)$
3. 计算差值：$\Delta\lambda = \lambda_{	ext{目标}} - \lambda_\odot$
4. 修正时刻：$t_1 = t_0 + rac{\Delta\lambda}{n_\odot}$
5. 重复直到 $|\Delta\lambda| < \epsilon$

输出：精确中气时刻

## 五、闰月计算的综合算法

### 5.1 完整闰月计算流程

**算法（闰月计算）**：

输入：农历年份

1. 计算该年冬至时刻 $t_{	ext{冬至}}$
2. 计算该年下一个冬至时刻 $t_{	ext{冬至}}'$
3. 计算两冬至之间的所有朔日
4. 计算两冬至之间的所有中气
5. 检查每个月是否包含中气
6. 若无中气月份存在，则该月为闰月

输出：闰月信息

### 5.2 农历月份确定

**算法（月份确定）**：

输入：朔日时刻，中气时刻

1. 从冬至所在月开始，依次编号为11月、12月、1月、...
2. 若某月无中气，设为闰月，继承前月名称加"闰"
3. 继续编号直到下一个冬至

输出：各月名称

## 七、闰月计算的精度分析

### 7.1 误差来源

**定义（误差来源）**：
1. 朔望月长度变化
2. 回归年长度变化
3. 黄经计算误差
4. 历元选择误差

### 7.2 精度评估

**定理（计算精度）**：使用高精度天文算法，朔日计算误差可控制在1秒以内。

### 7.3 历法换算精度

**定理（历法换算）**：农历与公历换算精度取决于朔日和中气计算精度，现代算法可达到日级精度。
